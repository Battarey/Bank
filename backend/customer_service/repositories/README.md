# Repositories Layer (Data Access)

Слой доступа к данным. Содержит репозитории для работы с таблицами БД через ORM и сырой SQL.

## Состав
- `customer.py` — Основной репозиторий для команд (Write Layer). Работает с агрегатом Пользователь + Профили через SQLAlchemy ORM.
- `queries.py` — Высокопроизводительный репозиторий для чтения (Read Layer/CQRS). Использует сырой SQL для агрегации данных профиля из 5+ таблиц.

## Особенности
- **Blind Index**: Методы `check_*_unique` используют предварительно рассчитанные хеши для проверки уникальности зашифрованных (PII) данных.
- **Дешифрование**: Репозиторий `queries.py` берет на себя ручную дешифровку полей, так как SQLAlchemy TypeDecorators не работают с сырыми SQL результатами.
- **Atomic updates**: Поддерживает метод `add_profile_part` для пошагового наполнения агрегата.
