# Services Layer (Business Logic)

Слой бизнес-логики. Содержит реализацию всех операций сервиса, правила валидации и координацию между репозиториями и событиями.

## Состав
- `onboarding.py` — Логика процесса регистрации: работа с Redis-черновиками, проверка кодов email, финализация в БД.
- `update.py` — Логика обновления профиля: нормализация данных, проверка уникальности (PII), логирование изменений.
- `account.py` — Логика удаления: перевод статуса, заморозка всех счетов клиента.

## Особенности
- **Транзакционность**: Все операции выполняются внутри `async with uow`.
- **Нормализация**: Перед сохранением данные приводятся к стандартному виду (Upper Case для имен, нормализация email/phone).
- **События**: Слой инициирует `LogEvent` и `NotificationEvent`.
