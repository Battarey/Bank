# Модуль создания аккаунта (create_account)

Реализует сложный процесс пошаговой регистрации (онбординга) нового клиента с использованием промежуточного хранилища.

## Файловая архитектура
- `router.py`: Эндпоинты `/registration` (Start, Steps, Finalize).
- `service.py`: Бизнес-логика валидации, нормализации и переноса данных из Redis в PostgreSQL.

## Шаги онбординга (Onboarding Steps)

1.  **Start**: Создание базовой записи в БД (`users`) со статусом `pending`.
2.  **Personal Data**: ФИО, дата рождения, пол.
3.  **Passport**: Серия, номер, кем и когда выдан.
4.  **Identifiers**: ИНН и СНИЛС (проходятся проверки уникальности).
5.  **Contacts**: Подтвержденный Email и номер телефона.
6.  **Finalize**: Коммит всех данных в PostgreSQL, активация аккаунта (`active`) и создание первого банковского счета.

## Технические детали
- **Redis Stack**: Используется для хранения JSON-черновиков для каждого шага. Это позволяет пользователю прервать регистрацию и вернуться к ней позже без потери данных.
- **Атомарная финализация**: На шаге `Finalize` данные из Redis переносятся в БД в рамках одной Unit of Work транзакции.
- **Очистка**: После успешного коммита в БД черновики из Redis удаляются автоматически.
