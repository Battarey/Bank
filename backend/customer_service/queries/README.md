# CQRS Query Layer (queries)

Слой высокопроизводительного чтения данных профиля клиента.

## Архитектура
Для получения полной информации о клиенте (профиля) сервис использует **CQRS (Command Query Responsibility Segregation)**. Это позволяет эффективно собирать данные, хранящиеся в разных нормализованных таблицах.

## Сборка профиля (Aggregation)
Запрос `get_full_profile` выполняет один атомарный SQL запрос с `LEFT JOIN` к 5 таблицам:
- `users` (базовый статус)
- `personal_data` (ФИО)
- `contacts` (Email, телефон)
- `passport` (Данные документа)
- `identifiers` (ИНН, СНИЛС)

## Безопасность и PII
Так как запрос выполняется в обход SQLAlchemy ORM (Raw SQL), автоматическая дешифровка полей через `TypeDecorator` не срабатывает. 
**В слое Query реализована ручная расшифровка чувствительных полей (PII):**
- Имена и фамилии.
- Контактные данные.
- Серия и номер паспорта.

Это гарантирует, что на выход API данные попадают в читаемом виде, при этом оставаясь зашифрованными на уровне диска.
