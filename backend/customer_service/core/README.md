# Core Layer (Infrastructure)

Инфраструктурный слой. Содержит общие компоненты, исключения и механизмы управления транзакциями.

## Состав
- `uow.py` — Реализация `CustomerUnitOfWork`, агрегирующая доступ к репозиториям.
- `exceptions.py` — Иерархия специфичных ошибок сервиса (Onboarding, UpdateData, Account).

## Особенности
- Использует `shared.bootstrap` для получения глобальных настроек и фабрики сессий БД.
- Определяет `get_uow` для инъекции зависимостей в FastAPI.
