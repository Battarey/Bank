# API Layer (Routers)

Слой роутеров FastAPI. Отвечает за определение эндпоинтов, валидацию входящих данных через Pydantic-схемы и делегирование выполнения бизнес-логики слою `services`.

## Состав
- `onboarding.py` — Процесс регистрации (KYC): пошаговое заполнение данных.
- `update.py` — Обновление персональных данных, паспортов и контактов.
- `account.py` — Управление аккаунтом (мягкое удаление).

## Особенности
- Использует `shared.internal_auth` для проверки ключей и извлечения `user_id`.
- Весь доступ к данным осуществляется через `CustomerUnitOfWork`.
