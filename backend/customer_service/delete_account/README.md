# Модуль удаления аккаунта (delete_account)

Реализует механизм контролируемого прекращения обслуживания клиента (Soft Delete).

## Логика процесса
Удаление аккаунта — это необратимая операция в рамках API, которая запускает каскад защитных мер:
1.  **Смена статуса**: Пользователь переводится в статус `deleted`.
2.  **Каскадная заморозка**: Все открытые банковские счета пользователя замораживаются системой безопасности (`frozen_by=system`) через связь с `account_service`.
3.  **Отзыв сессий**: Все активные токены доступа в Redis аннулируются, выполняется мгновенный Logout со всех устройств.
4.  **Уведомление**: Пользователю отправляется прощальное письмо (`account_deleted`).

## Ограничения после удаления
- Вход в мобильный банк или личный кабинет блокируется.
- Любые операции по счетам становятся невозможны.
- Email и телефон, связанные с удаленным аккаунтом, остаются в БД, что предотвращает повторную регистрацию на те же данные в целях безопасности.
