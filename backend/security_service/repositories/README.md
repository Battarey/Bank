# Repositories Layer (Data Access)

Слой доступа к данным безопасности.

## Состав
- `security.py` — Работа с PostgreSQL (балансы, история транзакций).
- `audit.py` — Работа с MongoDB (журнал сработавших правил и инцидентов).

## Особенности
- Использует гибридный подход для обеспечения производительности основного цикла и долгосрочного хранения аудита.
