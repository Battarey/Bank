# Хранилище инцидентов (store)

Модуль для долгосрочного хранения результатов проверок безопасности и фактов нарушения политик.

## Технические детали
Используется **MongoDB**, так как события безопасности имеют нерегулярную структуру (разные правила возвращают разные наборы деталей) и требуют высокой скорости записи.

## Конфигурация хранения
- **Коллекция**: `security_events`.
- **Индексы**: Создан TTL-индекс на поле `created_at`.
- **Срок хранения**: Документы автоматически удаляются из базы через **365 дней**.

## Структура документа
Каждая запись содержит:
- `account_id`: Идентификатор участника.
- `rule_name`: Имя сработавшего правила.
- `details`: JSON-объект с фактическими значениями (например, сумма, частота).
- `verdict`: Итоговое решение системы (allow/block).
- `created_at`: Метка времени UTC.

## Использование
Данные из этого хранилища используются службой безопасности для ручного разбора инцидентов и обучения моделей антифрода.
