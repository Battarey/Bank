# Services Layer (Antifraud & AML Rules)

Слой бизнес-логики анализа безопасности.

## Состав
- `antifraud.py` — Оркестрация проверок и принятие решения по транзакции.
- `rules.py` — Набор конкретных AML-правил (крупные суммы, дробление, аномальная частота и т.д.).

## Особенности
- Содержит "ядро" антифрод-системы.
- Правила работают с данными счетов через SQL-сессию и логируют подозрительные события в NoSQL аудит.
