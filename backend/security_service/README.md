# Security Service

Сервис обеспечения безопасности финансовых операций (Антифрод). Выполняет проверку каждой транзакции перед её окончательным проведением в системе.

## Файловая архитектура
```
security_service/
├── check/            # Модуль антифрод-проверок (Rules Engine)
├── store/            # Хранилище инцидентов (MongoDB)
├── exceptions.py     # Исключения безопасности
├── uow.py            # SecurityUnitOfWork (для атомарных операций)
├── main.py           # Точка входа FastAPI
└── README.md
```

## Принцип работы
1.  **Запрос**: При инициировании транзакции (перевод, снятие), сервис `transaction_service` отправляет запрос в `security_service/check`.
2.  **Анализ**: Запрос проходит через набор преднастроенных правил (AML/Fraud rules):
    - Проверка на превышение суточных лимитов.
    - Проверка на подозрительную частоту операций.
    - Сверка с черными списками.
3.  **Решение**: Сервис возвращает вердикт (разрешено/заблокировано).
4.  **Логирование**: Результат каждой проверки (особенно факты нарушения правил) сохраняется в MongoDB для последующего аудита.

## Технологии
- **FastAPI**: API Framework.
- **MongoDB**: Хранилище событий безопасности с TTL (1 год).
- **Pydantic v2**: Валидация структур данных.
