# Security Service (AML/CFT)

Внутренний сервис антифрод-мониторинга. Анализирует банковские операции в реальном времени на соответствие правилам безопасности и AML (Anti-Money Laundering).

## Файловая архитектура
```
security_service/
├── check/                # Основной модуль анализа
├── rules/                # Валидаторы AML правил
├── store/                # Репозиторий MongoDB
├── repository.py         # Репозиторий транзакций
├── uow.py                # SecurityUnitOfWork
├── main.py               # Точка входа
└── README.md
```

## Архитектура и Структура
Сервис реализует **4-слойную архитектуру** с хранением инцидентов в NoSQL:
-   **`check/`**: Основной модуль проверки транзакций.
-   **`uow.py`**: Реалзация `SecurityUnitOfWork` для атомарного анализа и логирования инцидентов.
-   **`store/`**: Слой работы с **MongoDB** для хранения детальных отчетов о нарушениях.
-   **`rules/`**: Набор правил (Validators) для проверки транзакций.

## API Эндпоинты

Сервис является внутренним и не доступен через API Gateway.

| Метод | Путь                      | Описание                                  |
|-------|---------------------------|-------------------------------------------|
| POST  | `/security/evaluations`   | Проверить транзакцию на соответствие правилам |

## AML Правила (Validators)

Система проверяет каждую транзакцию по 6 ключевым критериям:
1.  **Крупная сумма**: Разовая операция превышает установленный лимит.
2.  **Суточный объем**: Сумма всех операций за 24 часа выше нормы.
3.  **Частота операций (Rapid-Fire)**: Слишком много транзакций за короткий промежуток времени.
4.  **Дробление (Structuring)**: Серия мелких платежей, имитирующих обход лимитов.
5.  **Круглые суммы**: Аномальное количество операций с идеально круглыми суммами.
6.  **Географический риск**: (В разработке).

## Логика работы
-   **Fail-Open**: При недоступности сервиса транзакции в `Transaction Service` продолжают выполняться (не блокируем бизнес), но инцидент логируется для последующего разбора.
-   **Автозаморозка**: При критических нарушениях сервис инициирует событие `SecurityFreeze`, которое приводит к системной заморозке счета в `Account Service`.

## Технологии
-   **FastAPI**: API Framework.
-   **MongoDB**: Хранилище событий безопасности (NoSQL, TTL 365 дней).
-   **SQLAlchemy 2.0**: Чтение истории транзакций для анализа лимитов.
-   **RabbitMQ**: Доменные события безопасности.
