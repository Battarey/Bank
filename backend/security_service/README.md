# Security Service

Микросервис антифрод-мониторинга и AML-анализа банковских операций. Отвечает за выявление подозрительных транзакций и соблюдение требований банковской безопасности.

## Архитектура
Проект следует строгой 4-х слойной архитектуре (api, services, repositories, core).

### Файловая структура
```text
security_service/
├── api/                # Слой API: роутеры (antifraud.py)
├── services/           # Слой Services: логика антифрода и AML-правила
├── repositories/       # Слой Repositories: работа с Postgres и MongoDB
├── core/               # Слой Core: UoW, config, exceptions
├── main.py             # Точка входа и Health Checks
├── tests/              # Юнит-тесты
└── README.md
```

## Бизнес-логика (AML Rules)
Сервис проверяет каждую транзакцию по набору правил:
1. **Large Single Tx**: Операции свыше 600,000 RUB.
2. **Daily Amount**: Суммарный объем за 24ч свыше 1,000,000 RUB.
3. **Daily Count**: Более 20 операций за 24ч.
4. **Rapid Fire**: Более 5 операций за 3 минуты.
5. **Structuring**: Признаки "дробления" транзакций (серии переводов чуть ниже лимита).
6. **Round Amount**: Серии крупных круглых сумм (признак обналичивания).

## Технологии
- **SQLAlchemy (PostgreSQL)**: Хранение балансов для анализа.
- **Motor (MongoDB)**: Долгосрочный аудит сработавших правил и инцидентов.
- **FastAPI**: API для внутренних проверок другими сервисами.
