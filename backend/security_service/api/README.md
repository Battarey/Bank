# API Layer (Antifraud Endpoints)

Слой API для взаимодействия с антифрод-системой.

## Состав
- `antifraud.py` — Эндпоинты для проверки транзакций на соответствие AML-правилам.

## Особенности
- Используется внутренними сервисами (`transaction_service`, `account_service`) для предварительной валидации финансовых операций.
- Требует `INTERNAL_API_KEY` для аутентификации.
