# API Layer (Routers)

Этот слой содержит определения эндпоинтов FastAPI и логику диспетчеризации запросов.

## Ответственность
- Определение путей (routes) и методов (GET, POST и т.д.).
- Валидация входящих данных через Pydantic-схемы.
- Интеграция с зависимостями авторизации (require_user_id).
- Вызов соответствующих методов из слоя `services`.
- Формирование итогового HTTP-ответа.

## Файлы
- `transactions.py`: Основной роутер для выполнения финансовых операций.
- `history.py`: Роутер для получения истории транзакций и выписок.
