# Clients Layer

Этот слой инкапсулирует взаимодействие с внешними микросервисами по протоколу HTTP.

## Ответственность
- Инициализация и управление жизненным циклом HTTP-клиентов (httpx).
- Обработка сетевых ошибок и таймаутов.
- Инкапсуляция логики авторизации между сервисами (X-Internal-Key).
- Преобразование ответов внешних систем во внутренние типы данных.

## Файлы
- `currency.py`: Клиент для работы с Currency Service (получение курсов валют).
- `security.py`: Клиент для работы с Security Service (проверка транзакций на фрод).
