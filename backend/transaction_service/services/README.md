# Service Layer

Слой бизнес-логики, оркестрирующий выполнение всех операций сервиса.

## Ответственность
- Описание правил предметной области (финансовые транзакции).
- Оркестрация работы репозиториев, клиентов и Unit of Work.
- Управление событиями уведомлений и логов аудита.
- Реализация проверок безопасности и валютных конвертаций.

## Файлы
- `deposit.py`: Логика пополнения счетов.
- `withdrawal.py`: Логика снятия наличных и списаний.
- `transfer.py`: Логика межбанковских переводов и конвертации.
- `history.py`: Логика получения и фильтрации истории операций.
