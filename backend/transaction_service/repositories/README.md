# Repository Layer

Слой доступа к данным, отвечающий за выполнение запросов к базе данных PostgreSQL.

## Ответственность
- Выполнение CRUD-операций через SQLAlchemy (Command Side).
- Реализация атомарных блокировок на уровне БД (`FOR UPDATE`).
- Выполнение оптимизированных запросов на чтение истории (Query Side / CQRS).
- Сокрытие деталей реализации БД от слоев бизнес-логики.

## Файлы
- `transaction.py`: Основной репозиторий для записи транзакций и блокировки счетов.
- `history.py`: Query-репозиторий для быстрого чтения истории через сырой SQL.
