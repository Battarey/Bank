# Transaction Service

Центральный сервис управления финансовыми операциями: пополнение, снятие, межбанковские переводы и предоставление истории операций.

## Файловая архитектура
```
transaction_service/
├── deposit/          # Модуль пополнения счёта
├── withdrawal/       # Модуль снятия средств (с проверкой баланса)
├── transfer/         # Модуль переводов (Conversion + Anti-fraud)
├── history/          # CQRS Query Layer для истории транзакций
├── exceptions.py     # Финансовые и системные исключения
├── uow.py            # TransactionUnitOfWork
├── main.py           # Точка входа FastAPI
└── README.md
```

## Ключевые особенности
1.  **Атомарность**: Использование паттерна Unit of Work гарантирует, что финансовый перевод либо выполнится полностью для обеих сторон, либо не выполнится вовсе.
2.  **Безопасность**: Интеграция с `security_service` перед каждой транзакцией для предотвращения мошенничества.
3.  **Cross-Currency**: Автоматический обмен валют при переводах между счетами в разных валютах (RUB/USD/EUR).
4.  **Высокая скорость чтения**: Оптимизированный слой истории транзакций (CQRS).

## Бизнес-логика
- **Точность**: Все расчеты проводятся в `Decimal` с округлением до 0.01.
- **Идемпотентность**: Поддержка клиентских ключей для защиты от дублирования операций.
- **Заморозка**: Автоматическая блокировка счетов при обнаружении подозрительных паттернов.

## 🛰 API Эндпоинты

Все запросы требуют заголовок `X-Internal-Key`.

| Метод | Путь                                | Описание                                       | Заголовки   |
|-------|-------------------------------------|------------------------------------------------|-------------|
| POST  | `/transactions`                     | Создать операцию (пополнение, снятие, перевод) | `X-User-ID` |
| GET   | `/accounts/{id}/transactions`       | История операций по конкретному счету          | `X-User-ID` |
| GET   | `/health`                           | Проверка состояния сервиса                     | -           |

## Технологии
- **FastAPI**: API Framework.
- **PostgreSQL**: Хранилище счетов и транзакций.
- **Redis**: Временное кеширование результатов проверок и курсов.
- **RabbitMQ**: Публикация событий уведомлений и аудита.
