# Core Layer (Infrastructure)

Ядро сервиса, содержащее общую инфраструктурную логику и настройки.

## Ответственность
- Управление конфигурацией через переменные окружения (`config.py`).
- Реализация паттерна Unit of Work (`uow.py`) для обеспечения атомарности.
- Определение иерархии бизнес-исключений (`exceptions.py`).
- Предоставление общих утилит и хелперов для других слоев (`utils.py`).

## Файлы
- `config.py`: Настройки Pydantic Settings.
- `uow.py`: Реализация TransactionUnitOfWork.
- `exceptions.py`: Глобальные исключения сервиса.
- `utils.py`: Хелперы для проверки прав и применения AML-заморозок.
