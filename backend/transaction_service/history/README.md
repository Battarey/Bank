# Модуль истории транзакций (history)

Слой высокопроизводительного чтения истории операций по счёту.

## Архитектура (CQRS)
Для отображения истории используется **CQRS Query Layer**. Вместо использования тяжелого ORM, запросы выполняются напрямую к базе данных PostgreSQL через оптимизированный SQL.

## Функционал
- **Пагинация**: Поддержка параметров `limit` и `offset`.
- **Фильтрация**: Возможность отбора по типу операции (`deposit`, `withdrawal`, `transfer`) и направлению (`incoming`, `outgoing`).
- **Сортировка**: Транзакции всегда возвращаются в порядке убывания даты (`created_at DESC`).

## Оптимизация
Репозиторий `history/repository.py` выполняет один-два быстрых запроса (данные + общее количество) и напрямую маппит результат в Pydantic-схемы `TransactionResponse`, минимизируя нагрузку на CPU и память.
