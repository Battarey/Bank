# Модуль пополнения (deposit)

Обеспечивает зачисление внешних средств на банковские счета пользователей.

## Файлы
- `router.py`: Эндпоинт `POST /accounts/{id}/deposit`.
- `service.py`: Атомарная логика обновления баланса.

## Алгоритм операции
1.  **Блокировка**: Счёт блокируется в БД через `SELECT ... FOR UPDATE`.
2.  **Валидация**: Проверка существования счёта и его статуса (`open`).
3.  **Обновление**: Баланс увеличивается на указанную сумму.
4.  **Запись**: Создается транзакция типа `deposit` с направлением `incoming`.
5.  **События**: При успехе генерируются события `transaction_deposit` (Email) и `LogEvent` (Аудит).
