# Модуль переводов (transfer)

Самый сложный модуль системы, обеспечивающий движение средств между счетами внутри банка.

## Файлы
- `router.py`: Эндпоинт `POST /accounts/{id}/transfer`.
- `service.py`: Оркестрация перевода, валютная конвертация и антифрод.

## Атомарность и Deadlock Safety
Для безопасного проведения перевода между двумя счетами используется стратегия **Lock Ordering**:
- Идентификаторы счетов сортируются перед блокировкой.
- Блокировка `FOR UPDATE` выполняется всегда в одном и том же порядке (по UUID), что математически исключает возникновение взаимных блокировок (deadlocks) при параллельных переводах между одними и теми же участниками.

## Идемпотентность
Для предотвращения повторных списаний при ошибках сети сервис поддерживает `Idempotency-Key` (UUID). Если операция с таким ключом уже была успешно проведена, сервис вернет результат существующей транзакции без повторного списания.

## Интеграция с Security
Перед выполнением проводки запрос отправляется в `security_service`. 
**Если антифрод-система блокирует перевод:**
1. Операция прерывается.
2. Счёт отправителя **автоматически замораживается** (`status = frozen`).
3. Пользователю отправляется уведомление `security_freeze` с указанием причины нарушения.

## Валютная конвертация
Если счета отправителя и получателя имеют разные валюты (например, RUB и USD), сервис автоматически:
1. Запрашивает актуальный курс в `currency_service`.
2. Рассчитывает сумму зачисления с округлением `ROUND_HALF_UP`.
3. Фиксирует курс обмена в деталях транзакции.
