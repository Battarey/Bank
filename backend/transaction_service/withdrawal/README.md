# Модуль снятия средств (withdrawal)

Управляет процессом списания средств со счета пользователя (нал/безнал).

## Файлы
- `router.py`: Эндпоинт `POST /accounts/{id}/withdraw`.
- `service.py`: Проверка баланса и проведение списания.

## Бизнес-правила
1.  **Принадлежность**: Операция разрешена только владельцу счёта.
2.  **Проверка средств**: Списание невозможно, если сумма превышает текущий баланс счёта.
3.  **Статус**: Счёт должен быть в статусе `open`. С замороженных или закрытых счетов снятие запрещено.
4.  **Security Check**: Каждая операция снятия проходит проверку в `security_service` на предмет подозрительной активности.

## Результат
- `balance` уменьшается на сумму операции.
- Создается запись типа `withdrawal` с направлением `outgoing`.
- Отправляется уведомление `transaction_withdrawal` пользователю.
