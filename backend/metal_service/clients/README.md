# Clients Layer (External APIs)

Слой внешних клиентов. Содержит логику взаимодействия с Metals.Dev API.

## Состав
- `metal_client.py` — Асинхронный клиент для получения котировок в реальном времени.

## Особенности
- Реализует кэширование цен в памяти (`_cache`) с настраиваемым TTL.
- Использует `httpx` для сетевого взаимодействия.
