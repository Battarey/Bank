# Metal Service

Сервис для получения актуальных рыночных котировок драгоценных металлов (золото, серебро, платина, палладий).

## Архитектура
Микросервис построен по принципам **Layered Architecture** и строго следует 4-х слойной структуре (api, services, repositories, core) с добавлением слоя `clients` для внешних интеграций.

### Файловая структура
```text
metal_service/
├── api/                # Слой Routers: получение актуальных котировок
├── services/           # Слой Services: бизнес-логика и агрегация цен
├── clients/            # Слой Clients: интеграция с Metals.Dev API
├── repositories/       # Слой Repository: (зарезервирован, не используется)
├── core/               # Инфраструктурный слой: config, exceptions
├── main.py             # Точка входа в приложение
├── tests/              # Юнит и интеграционные тесты
└── README.md
```

## Поддерживаемые металлы
Сервис оперирует международными банковскими кодами металлов:
- **XAU**: Золото (Gold).
- **XAG**: Серебро (Silver).
- **XPT**: Платина (Platinum).
- **XPD**: Палладий (Palladium).

## Бизнес-логика
- **Единица измерения**: Все цены возвращаются в расчете за **1 грамм** металла.
- **Валюта**: Котировки могут быть получены в рублях (RUB), долларах (USD) или евро (EUR) в зависимости от запроса.
- **Источник**: Данные запрашиваются через внешний API Metals.Dev в режиме реального времени.

## 🛰 API Эндпоинты

Все запросы требуют заголовок `X-Internal-Key`.

| Метод | Путь                            | Описание                                  |
|-------|---------------------------------|-------------------------------------------|
| GET   | `/metals/rates`                 | Актуальные котировки металлов за 1 грамм  |
| GET   | `/health`                       | Проверка состояния сервиса                |

## Технологии
- **FastAPI**: API Framework.
- **Httpx**: Асинхронные HTTP-запросы к внешним API.
- **Redis**: Используется для кратковременного кеширования котировок в целях снижения нагрузки на внешние API.
