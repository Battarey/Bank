# Metal Service

Сервис для получения актуальных банковских котировок на драгоценные металлы: золото, серебро, платину и палладий. Выступает в роли надежного прокси для внешних аналитических API.

## Файловая архитектура
```
metal_service/
├── rates/                # Агрегация котировок
├── metal_client.py       # Клиент Metals.Dev
├── main.py               # Точка входа
└── README.md
```

## Архитектура и Структура
Простой сервисный слой для агрегации данных:
-   **`rates/`**: Модуль обработки и нормализации котировок.
-   **`metal_client.py`**: Асинхронный HTTP-клиент для Metals.Dev API.
-   **Кэширование**: Внутреннее кэширование котировок (30 секунд) для минимизации внешних запросов.

## API Эндпоинты

Все запросы требуют заголовок `X-Internal-Key`.

| Метод | Путь                      | Описание                                  |
|-------|---------------------------|-------------------------------------------|
| GET   | `/metals/rates`           | Получить цены на все металлы (за грамм)   |
| GET   | `/metals/rates/{base}/{target}` | Получить цену конкретной пары (напр. RUB/XAU) |

---

## Бизнес-логика

### Котировки металлов
-   Данные по умолчанию возвращаются в расчете на **1 грамм** металла.
-   Поддерживаемые металлы: `XAU` (Gold), `XAG` (Silver), `XPT` (Platinum), `XPD` (Palladium).
-   Базовая валюта по умолчанию — `RUB`.

### Интеграция
Сервис не использует локальную базу данных, являясь " stateless"-прокси, что обеспечивает мгновенный запуск и высокую масштабируемость.

## Технологии
-   **FastAPI**: API Framework.
-   **Httpx**: Асинхронное взаимодействие с внешними провайдерами.
-   **Metals.Dev API**: Источник рыночных данных.
-   **Python 3.12**: asyncio-стек.
