# Metal Service

Сервис для получения актуальных рыночных котировок драгоценных металлов (золото, серебро, платина, палладий).

## Файловая архитектура
```
metal_service/
├── rates/            # Модуль котировок (Router + Service)
├── exceptions.py     # Специфичные ошибки (RateUnavailable)
├── metal_client.py   # Внутренний клиент для Metals.Dev API
├── main.py           # Точка входа FastAPI
└── README.md
```

## Поддерживаемые металлы
Сервис оперирует международными банковскими кодами металлов:
- **XAU**: Золото (Gold).
- **XAG**: Серебро (Silver).
- **XPT**: Платина (Platinum).
- **XPD**: Палладий (Palladium).

## Бизнес-логика
- **Единица измерения**: Все цены возвращаются в расчете за **1 грамм** металла.
- **Валюта**: Котировки могут быть получены в рублях (RUB), долларах (USD) или евро (EUR) в зависимости от запроса.
- **Источник**: Данные запрашиваются через внешний API Metals.Dev в режиме реального времени.

## Технологии
- **FastAPI**: API Framework.
- **Httpx**: Асинхронные HTTP-запросы к внешним API.
- **Redis**: Используется для кратковременного кеширования котировок в целях снижения нагрузки на внешние API.
