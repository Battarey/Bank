# Metal Service

![Python 3.12](https://img.shields.io/badge/python-3.12-blue.svg)
![FastAPI](https://img.shields.io/badge/FastAPI-0.109+-009688.svg)
![Status: Ready](https://img.shields.io/badge/Status-Ready-brightgreen.svg)

Информационный микросервис для предоставления актуальных котировок драгоценных металлов (золото, серебро, платина, палладий) на мировых рынках.

## Архитектура

Сервис следует облегченной версии 4-х слойной архитектуры, так как фокусируется на интеграции с внешними API и кэшировании данных.

```text
metal_service/
├── api/                # Эндпоинты получения цен
├── services/           # Бизнес-логика: нормализация цен, расчет граммовки
├── clients/            # Внешний клиент: Metals.dev API
├── core/               # Инфраструктура: config, exceptions
├── main.py             # Точка входа
└── README.md
```

## Функционал

1.  **Реалтайм-котировки**: Получение цен на драгоценные металлы к мировым валютам (USD, RUB, EUR).
2.  **Грамм-стандарт**: Автоматический пересчет цен из тройских унций (биржевой стандарт) в граммы.
3.  **Кэширование**: Оптимизация количества запросов к внешнему API через внутренний кэш-слой.

## API Спецификация

| Метод | Путь                 | Описание                                  | Заголовки |
|-------|----------------------|-------------------------------------------|-----------|
| GET   | `/metals/prices`     | Текущие цены на золото, серебро и др.     | -         |
| GET   | `/health`            | Проверка состояния сервиса                | -         |

## Доменные события (Domain Events)

На текущем этапе сервис работает в режиме Query-only и не инициирует доменных событий.

## Переменные окружения

| Ключ | Описание | Значение по умолчанию |
|------|----------|-----------------------|
| `APP_ENV` | Окружение (local, test, dev, prod) | `local` |
| `METALS_DEV_API_KEY` | Ключ доступа к Metals.Dev API | - |
| `METAL_RATE_CACHE_TTL` | Время жизни кэша котировок (сек) | `30` |
| `INTERNAL_API_KEY` | Секретный ключ для авторизации запросов | - |

## Технологии
- **FastAPI**: Фреймворк API.
- **Metals.dev API**: Источник биржевых данных.
- **Pydantic V2**: Валидация и конфигурация.
