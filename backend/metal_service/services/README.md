# Services Layer (Business Logic)

Слой бизнес-логики. Обрабатывает запросы цен и агрегирует данные от клиентов.

## Состав
- `rates.py` — Логика получения цен всех поддерживаемых металлов.

## Особенности
- Координирует работу с внешними клиентами в слое `clients`.
- Обрабатывает ошибки внешних API и выбрасывает бизнес-исключения `RateUnavailable`.
