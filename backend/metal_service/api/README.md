# API Layer (Routers)

Слой роутеров FastAPI. Отвечает за определение эндпоинтов для получения котировок металлов.

## Состав
- `rates.py` — Получение цен на золото, серебро, платину и палладий.

## Особенности
- Использует `shared.schemas` для передачи данных.
- Делегирует логику в слой `services`.
