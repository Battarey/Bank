# Модуль котировок металлов (rates)

Обеспечивает доступ к мировым рыночным ценам на драгоценные металлы.

## Файлы
- `router.py`: Эндпоинты `GET /metals/rates`.
- `service.py`: Получение, нормализация и кеширование цен.

## Основные операции

### Получение всех цен (`GET /metals/rates`)
Возвращает актуальную стоимость всех поддерживаемых металлов (XAU, XAG, XPT, XPD) в указанной валюте.
- **Параметр `currency`**: Позволяет переключать валюту цен (RUB, USD, EUR). По умолчанию — RUB.

## Логика работы
1. Запрос поступает в `MetalService`.
2. Проверяется наличие свежего кеша в Redis (TTL 5 минут).
3. При отсутствии кеша выполняется запрос к внешнему API Metals.Dev.
4. Цены конвертируются из тройских унций (стандарт API) в граммы (стандарт банка).
5. Результат кешируется и возвращается клиенту.

## Исключения
- `RateUnavailable` (502): Возникает при недоступности внешнего API или ошибке парсинга цен.
