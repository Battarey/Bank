# Ядро истории действий (history_core)

Специализированная инфраструктура для работы с базой данных `postgres_history`.

## Назначение
Модуль отделен от основного `database_core` для обеспечения независимости логов аудита от основной операционной базы данных.

## Состав модуля
- `models.py`: Модель `UserAction`, описывающая структуру записей аудита.
- `history_db.py`: Конфигурация соединения и фабрика сессий для отдельной БД истории.

## Использование
Используется преимущественно в `log_service` для записи и во всех сервисах через CQRS-репозитории для чтения истории действий пользователей.
