# Redis Клиенты (redis_sessions / redis_onboarding)

Специализированные асинхронные клиенты для управления состоянием в оперативной памяти.

## 1. Сессии (redis_sessions)
Управление активными сессиями пользователей.
- Хранение токенов доступа.
- Реализация "скользящей экспирации" (продление сессии при активности).

## 2. Онбординг (redis_onboarding)
Хранение черновиков (Drafts) при регистрации новых клиентов.
- Использует **Redis Stack (JSON)** для хранения сложных структур данных.
- Позволяет пользователю прерывать и продолжать заполнение анкеты на любом шаге.
- Очистка данных по истечении TTL, если онбординг не был завершен.

## Технологии
- `redis-py` (asyncion): Асинхронный драйвер.
- `RedisJSON`: Для эффективной работы с вложенными структурами в процессах регистрации.
