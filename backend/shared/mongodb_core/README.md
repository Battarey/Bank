# Ядро MongoDB (mongodb_core)

Общая инфраструктура для работы с базами данных MongoDB в асинхронном режиме.

## Назначение
Модуль обеспечивает унифицированный способ подключения к MongoDB, мониторинга состояния (healthcheck) и управления структурой данных (индексами) для всех Python-микросервисов проекта.

## Состав модуля
- `db.py`: 
  - `init_mongodb`: Инициализация клиента `motor.motor_asyncio.AsyncIOMotorClient`, установка глобального объекта базы данных и автоматическое создание индексов.
  - `get_mongodb`: Функция-зависимость для получения доступа к текущей БД.
  - `ping_mongodb`: Инструмент для проверки работоспособности (healthcheck).
  - `close_mongodb`: Корректное закрытие соединений.

## Использование
Используется в следующих компонентах:
- `notification_service`: Для хранения журналов отправленных уведомлений.
- `security_service`: Для фиксации событий безопасности и результатов AML-анализа.
