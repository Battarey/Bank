# Общие утилиты (utils)

Набор вспомогательных инструментов для обеспечения чистоты кода и безопасности.

## Состав модуля
- `normalize.py`: Функции приведения данных к единому формату (Email к нижнему регистру, ФИО к верхнему, очистка телефонов).
- `exceptions.py`: Глобальная иерархия исключений `BaseBusinessError`.
- `exceptions_handler.py`: Автоматическая интеграция обработки ошибок в FastAPI приложения.
- `security.py`: Хеширование (bcrypt) и утилиты безопасного сравнения строк.

## Обработка исключений
Использование `setup_exception_handlers(app)` позволяет сервисам бросать бизнес-исключения, которые автоматически конвертируются в корректные JSON-ответы с нужным HTTP-статусом, избавляя от дублирования `try-except` блоков в роутерах.
