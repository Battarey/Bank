# ClickHouse Конектор (clickhouse_core)

Инструментарий для высокопроизводительной записи аналитических логов и системных событий в ClickHouse.

## Принцип работы
Для обеспечения максимальной скорости вставки используется асинхронный драйвер и прямые SQL-запросы `INSERT`.

## Основные функции
- `init_clickhouse()`: Инициализация пула соединений при старте сервиса.
- `close_clickhouse()`: Корректное завершение работы.
- `insert_log_event()`: Маппинг данных из Pydantic-моделей в структуру таблицы `log_events`.

## Оптимизация
Вставка выполняется без использования ORM, что позволяет `log_service` обрабатывать тысячи событий в секунду с минимальными задержками.
