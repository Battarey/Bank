# SQLAlchemy Модели (models)

Централизованное описание схемы базы данных PostgreSQL `bank_core`.

## Безопасность и PII
Для защиты персональных данных (номер паспорта, адрес) используется тип **`EncryptedString`**. 
- Данные шифруются на стороне приложения перед записью в БД.
- Ключ шифрования хранится в переменных окружения.
- Это предотвращает утечку данных даже при полном дампе базы данных.

## Основные сущности
- `User`: Базовая запись клиента и его статус.
- `PersonalData` / `Passport`: Персональная информация (PII).
- `Contact`: Уникальные Email и Телефон (используются для логина).
- `BankAccount`: Баланс, валюта и состояние счета.
- `Transaction`: История движений средств (Immutable записи).

## Уровни доступа
Модели являются "общими" (Shared), что позволяет всем микросервисам работать с единой структурой таблиц через общие миграции Alembic.
