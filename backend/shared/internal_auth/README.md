# Внутренняя авторизация (internal_auth)

Механизм обеспечения безопасности межсервисного взаимодействия (Service-to-Service).

## Принцип работы
Для защиты внутренних эндпоинтов от несанкционированного доступа извне используется заголовок **`X-Internal-Key`**.

1.  **API Gateway**: Генерирует и добавляет секретный ключ во все запросы, направляемые во внутреннюю сеть.
2.  **Микросервисы**: Используют декоратор или Middleware из этого модуля для проверки ключа.
3.  **Валидация**: Выполняется криптографически безопасное сравнение (`secrets.compare_digest`) полученного ключа с эталонным значением из переменных окружения.

## Использование
Любой эндпоинт, помеченный как `internal`, будет возвращать `403 Forbidden`, если запрос пришел без корректного ключа. Это предотвращает прямой доступ к методам микросервисов в обход шлюза.
