# Pydantic Модели (schemas)

Централизованный реестр схем данных для валидации API-запросов, ответов и сообщений в RabbitMQ.

## Организация
Схемы разделены по доменным областям:
- `user.py`: Профиль, регистрация, личные данные.
- `account.py`: Счета, балансы, статусы.
- `transaction.py`: Пополнение, снятие, переводы, история.
- `auth.py`: Вход, сессии, токены.
- `security.py`: Проверки, нарушения, лимиты.

## Преимущества
- **Типизация**: Использование Type Hints для обеспечения безопасности кода.
- **Сериализация**: Автоматическая конвертация ORM-моделей в JSON (через `model_validate`).
- **Единый стандарт**: Все сервисы обмениваются данными, используя общие схемы, что исключает ошибки несовместимости интерфейсов.
