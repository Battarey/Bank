# Клубничный онбординг (redis_onboarding)

Клиент для работы с временными данными многошаговой регистрации пользователей в RedisJSON.

## Как работает
В процессе онбординга (6 шагов) данные не сохраняются в PostgreSQL до самого финала. Вместо этого они накапливаются в Redis в виде JSON-документа.

## Возможности
- Сохранение частичных данных (Drafts).
- Быстрый доступ по токену регистрации.
- Валидация всей структуры JSON за одну операцию.

## TTL
Данные онбординга имеют ограниченный срок жизни (обычно 1 час), после чего автоматически удаляются из Redis.
