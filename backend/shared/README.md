Общая библиотека компонентов, моделей и инструментов, используемая всеми микросервисами банковской системы. Служит «единым источником истины» для всей инфраструктуры и гарантирует консистентность кода.

## Структура библиотеки

```text
shared/
├── database_core/      # Базовые классы БД, UoW и CQRS паттерны
├── models/             # Декларативные ORM-схемы (PostgreSQL)
├── schemas/            # Общие Pydantic-модели и DTO
├── events/             # Базовые классы событий и логика RabbitMQ
├── internal_auth/      # Middleware для проверки X-Internal-Key
├── redis_sessions/     # Управление сеансами и токенами
├── redis_onboarding/   # Логика временного хранения KYC-данных
├── clickhouse_core/    # Клиент и инструменты для аналитики
├── mongodb_core/       # Инструменты для работы с логами в MongoDB
└── utils/              # Хелперы: нормализация, безопасность, ошибки
```

## Правила использования

1.  **Чистота инфраструктуры**: Shared не должна содержать бизнес-логику конкретных сервисов. Только общие интерфейсы, модели данных и инфраструктурные обертки.
2.  **Обратная совместимость**: Изменения в этой директории (особенно в `models` или `events`) затрагивают всю систему. Требуется проверка всех зависимых сервисов.
3.  **Изоляция импортов**: Все внутренние импорты должны быть абсолютными. Избегайте циклических зависимостей между подмодулями shared.

## Технологический Стек

-   **SQLAlchemy 2.0**: Основной ORM для реляционных БД.
-   **Pydantic v2**: Строгая типизация и валидация на всех уровнях.
-   **Aio-pika**: Асинхронный клиент RabbitMQ.
-   **Motor / Go-Redis**: Асинхронные клиенты для NoSQL хранилищ.
-   **Cryptography**: Библиотеки шифрования для защиты PII-данных.

## Переменные окружения (Общие)

Эти переменные используются базовыми классами конфигурации в `shared/config/`:

| Ключ | Описание | Значение по умолчанию |
|------|----------|-----------------------|
| `APP_ENV` | Окружение выполнения | `local` |
| `SECRET_KEY` | Секрет для подписи токенов и шифрования | - |
| `INTERNAL_API_KEY` | Ключ для межсервисной аутентификации | - |
