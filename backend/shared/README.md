# Shared Library

Общая библиотека компонентов, моделей и инструментов, используемая всеми микросервисами банковской системы. Служит "единым источником истины" для всей инфраструктуры.

## Структура библиотеки
- **database_core**: Ядро работы с БД, реализации паттернов UoW и CQRS.
- **models**: Описание ORM-схемы PostgreSQL и механизмы шифрования данных.
- **schemas**: Pydantic-схемы для валидации запросов и ответов.
- **rabbitmq / events**: Инфраструктура событий (EDA).
- **redis_***: Клиенты для управления сессиями и многошаговым онбордингом.
- **internal_auth**: Безопасность межсервисных вызовов (Internal Key).
- **utils**: Обработка ошибок, нормализация данных, безопасность.
- **clickhouse_core**: Инструменты записи аналитических логов.
- **mongodb_core**: Инфраструктура для работы с MongoDB (асинхронный клиент, индексы).

## Правила использования
1.  **Запрет логики**: Shared не должна содержать бизнес-логику конкретных сервисов. Только инфраструктурные кирпичики и описание структур данных.
2.  **Обратная совместимость**: Изменения в Shared (особенно в `models` или `events`) затрагивают всю систему. Требуется тщательное тестирование зависимостей.
3.  **Импорты**: Все импорты внутри Shared должны быть абсолютными или корректными относительными, чтобы избежать циклических зависимостей.

## Технологии
- **SQLAlchemy 2.0**: ORM.
- **Pydantic v2**: Схемы и валидация.
- **Aio-pika**: Сообщения.
- **Cryptography / Bcrypt**: Безопасность.
