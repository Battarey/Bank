# CQRS Query Layer (queries)

Слой высокопроизводительного чтения данных, оптимизированный для получения информации о счетах без накладных расходов SQLAlchemy ORM.

## Архитектура
Для выполнения `GET`-запросов сервис использует **CQRS (Command Query Responsibility Segregation)**. Вместо использования `BankAccountRepository` (который работает с ORM-объектами), запросы направляются в `AccountQueryRepository`.

## Преимущества реализации
1.  **Raw SQL**: Использование чистого SQL-кода для выборки данных.
2.  **Bypass ORM**: Отсутствие этапа преобразования данных из БД в объекты моделей SQLAlchemy, что значительно увеличивает скорость на больших объемах.
3.  **Прямой маппинг в Pydantic**: Данные из SQL-строк напрямую преобразуются в Pydantic-схемы `AccountResponse`.

## Оптимизированные запросы
- `list_by_user_with_total`: Получение списка всех счетов пользователя (включая замороженные и закрытые) с автоматической сортировкой по дате открытия (`opened_at DESC`).
- `get_by_id_raw`: Точечное получение детальной информации по UUID счёта.

## Структура
- `repository.py`: Реализация SQL-запросов и логики маппинга.
- Наследуется от `shared.database_core.base_query_repository.BaseQueryRepository`.
