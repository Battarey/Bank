# Модуль заморозки счетов (freeze_account)

Управление временным приостановлением обслуживания банковских счетов.

## Файлы
- `router.py`: Эндпоинты `/suspensions` (POST/DELETE).
- `service.py`: Логика индивидуальной и каскадной заморозки.

## Уровни заморозки

### 1. Пользовательская заморозка
Выполняется клиентом через API. Блокирует любые финансовые транзакции по счёту.
- **Статус**: `frozen`
- **frozen_by**: `user`

### 2. Системная заморозка (Cascade)
Выполняется автоматически системой безопасности при обнаружении подозрительной активности или блокировке всего аккаунта пользователя (`cascade_freeze`).
- **frozen_by**: `system`
- **Ограничение**: Пользователь **не может** самостоятельно разморозить такой счёт (`UnfreezeNotAllowed`).

## Команды разморозки
`DELETE /accounts/{id}/suspensions` — снимает блокировку, если она была установлена пользователем. Системные блокировки снимаются только через внутренние вызовы (`cascade_unfreeze`).

## Исключения
- `UnfreezeNotAllowed` (403): Попытка разморозки системной блокировки пользователем.
- `AccountAlreadyFrozen` (409): Счёт уже находится в статусе заморозки.
