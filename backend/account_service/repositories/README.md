# Repository Layer

Слой доступа к данным, отвечающий за выполнение запросов к базе данных PostgreSQL.

## Ответственность
- Выполнение CRUD-операций через SQLAlchemy (Command Side).
- Реализация атомарных блокировок и проверок целостности.
- Выполнение оптимизированных запросов на чтение данных счетов (Query Side / CQRS).
- Сокрытие деталей реализации БД от слоев бизнес-логики.

## Файлы
- `account.py`: Репозиторий для управления состоянием счетов и проверки владельцев.
- `queries.py`: Query-репозиторий для быстрого чтения данных через сырой SQL.
