# Модуль открытия счетов (open_account)

Управляет жизненным циклом создания банковских счетов, получением их списков и детальной информации.

## Файлы
- `router.py`: FastAPI Router с эндпоинтами `/accounts`.
- `service.py`: Бизнес-логика открытия, лимитов и валидации владельца.

## Основные операции

### 1. Открытие счёта (open_account)
- **Валидация владельца**: Проверка существования клиента и его активного статуса через `uow.accounts`.
- **Контроль лимитов**: Максимум 3 открытых счёта на комбинацию [тип + валюта].
- **Генерация номера**: 20-значный уникальный номер с проверкой коллизий в БД (до 10 итераций).
- **События**: При успехе генерируются события `account_opened` (Email) и `open_account` (Аудит).

### 2. Листинг и детализация
Используют **CQRS Query Layer** (`queries/`) для быстрого чтения данных напрямую из PostgreSQL через SQL-запросы, минуя SQLAlchemy ORM.

## Исключения
- `AccountLimitReached` (409): Превышен лимит открытых счетов.
- `AccountConflict` (409): Ошибка уникальности номера счёта.
- `AccountNotFound` (404): Счёт не найден или не принадлежит пользователю.
