# Модуль закрытия счетов (close_account)

Реализует механизм «мягкого удаления» банковских счетов.

## Файлы
- `router.py`: Эндпоинт `DELETE /accounts/{account_id}`.
- `service.py`: Валидация условий закрытия и обновление статуса.

## Правила закрытия
1.  **Принадлежность**: Счёт должен принадлежать пользователю, чей `user_id` передан в запросе.
2.  **Статус**: Только активные счета (`open`) могут быть закрыты.
3.  **Баланс**: Закрытие разрешено только при балансе **равном 0.00**.
4.  **Результат**: `status` меняется на `closed`, устанавливается дата `closed_at`. Физическое удаление не производится.

## Побочные эффекты
- Генерация события `account_closed` для уведомления клиента по Email.
- Запись действия в системный аудит-лог через `LogEvent`.

## Исключения
- `AccountNonZeroBalance` (409): Невозможно закрыть счёт с положительным остатком.
- `AccountNotOpen` (409): Счёт уже закрыт или находится в заморозке.
