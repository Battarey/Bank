# Core Layer (Infrastructure)

Ядро сервиса, содержащее общую инфраструктурную логику и управление транзакциями.

## Ответственность
- Реализация паттерна Unit of Work (`uow.py`) для обеспечения атомарности операций и публикации событий.
- Определение иерархии бизнес-исключений (`exceptions.py`), интегрированных с глобальным обработчиком.
- Инициализация сессий базы данных через глобальный контейнер.

## Файлы
- `uow.py`: Реализация AccountUnitOfWork.
- `exceptions.py`: Глобальные исключения сервиса.
