# Service Layer

Слой бизнес-логики, оркестрирующий выполнение всех операций по управлению банковскими счетами.

## Ответственность
- Описание правил предметной области (статусы счетов, лимиты).
- Оркестрация работы репозиториев и Unit of Work.
- Управление событиями уведомлений и логов аудита.
- Реализация проверок на владение счетом и активность пользователя.

## Файлы
- `account.py`: Основная логика по открытию, закрытию, заморозке и разморозке счетов.
