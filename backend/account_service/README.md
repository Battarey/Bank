# Account Service

Микросервис управления банковскими счетами: открытие, мониторинг, блокировка и закрытие. Реализует паттерны **Unit of Work** и **CQRS** для высокой надежности и производительности.

## Файловая архитектура
```
account_service/
├── open_account/         # Модуль открытия счетов
├── close_account/        # Модуль закрытия
├── freeze_account/       # Модуль заморозки/разморозки
├── queries/              # CQRS Query Layer
├── repository.py         # Репозиторий BankAccount
├── uow.py                # AccountUnitOfWork
├── main.py               # Точка входа
└── README.md
```

## Архитектура и Структура
Сервис построен по 4-слойному принципу:
-   **`open_account/`**, **`close_account/`**, **`freeze_account/`**: Группировка по доменным под-модулям (Router + Service).
-   **`queries/`**: Слой чтения (CQRS Query Layer) для оптимизированных выборок.
-   **`uow.py`**: Реализация `AccountUnitOfWork` для атомарных операций.
-   **`repository.py`**: ORM-репозиторий для сущности `BankAccount`.

## 🛰 API Эндпоинты

Все запросы требуют заголовки `X-Internal-Key` и `X-User-ID`.

| Метод  | Путь                         | Описание                                  |
|--------|------------------------------|-------------------------------------------|
| POST   | `/accounts`                  | Открыть новый счёт                        |
| GET    | `/accounts`                  | Получить список всех счетов пользователя  |
| GET    | `/accounts/{id}`             | Детали конкретного счёта                  |
| DELETE | `/accounts/{id}`             | Закрыть счёт (баланс должен быть 0)       |
| POST   | `/accounts/{id}/suspensions` | Приостановить обслуживание (заморозка)    |
| DELETE | `/accounts/{id}/suspensions` | Возобновить обслуживание (разморозка)     |

## 💼 Бизнес-правила

### Открытие счёта
-   Генерируется уникальный 20-значный номер по банковскому стандарту.
-   **Лимит:** максимум 3 открытых счёта на комбинацию `тип + валюта`.
-   Начальный статус: `open`, баланс: `0.00`.

### Закрытие счёта (`soft delete`)
-   Счёт не удаляется физически, статус меняется на `closed`.
-   **Условие:** Баланс должен быть строго `0.00`.

### Приостановка обслуживания (Заморозка)
-   Блокирует все исходящие операции по счёту. Входящие операции разрешены.
-   **Системная заморозка:** Пользователь не может самостоятельно снять блокировку, установленную системой (напр. AML-проверкой).

## 📡 Доменные события (Domain Events)

События автоматически публикуются в RabbitMQ через `uow.commit()`:
-   **`AccountOpened`**: Триггерит приветственное письмо.
-   **`AccountClosed`**: Отправка уведомления о закрытии.
-   **`AccountFrozen` / `AccountUnfrozen`**: Уведомление о изменении статуса блокировки.
-   **`LogEvent`**: Регистрация всех действий в аудит-логе.
