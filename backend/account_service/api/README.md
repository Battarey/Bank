# API Layer (Routers)

Этот слой содержит определения эндпоинтов FastAPI и логику диспетчеризации запросов для управления счетами.

## Ответственность
- Определение путей (routes) и методов (GET, POST, DELETE).
- Валидация входящих данных через Pydantic-схемы.
- Интеграция с зависимостями авторизации (require_user_id).
- Вызов соответствующих методов из слоя `services`.
- Формирование итогового HTTP-ответа.

## Файлы
- `accounts.py`: Унифицированный роутер для открытия, закрытия, заморозки и получения информации о счетах.
