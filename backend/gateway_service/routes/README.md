# Маршрутизация (routes)

Определение точек входа API и их привязка к внутренним микросервисам системы.

## Структура маршрутов
Маршруты разделены на логические группы, соответствующие микросервисам:
- `auth.go`: Вход, выход, сессии, разблокировка.
- `account.go`: Управление счетами, балансы.
- `customer.go`: Онбординг, профиль пользователя.
- `transaction.go`: Переводы, пополнение, снятие.
- `currency.go` / `metal.go`: Курсы валют и драгметаллов.

## Принципы маппинга
Каждый файл в этой директории регистрирует группу путей с соответствующим префиксом и делегирует выполнение запросов в `proxy.ForwardRequest`.

Пример:
- Публичный `/api/v1/auth/login-pin` -> `auth_service:8001/sessions`
- Защищенный `/api/v1/accounts` -> `account_service:8002/accounts`

## Вспомогательные функции (`helpers.go`)
Содержит утилиты для извлечения параметров запроса и унификации ответов об ошибках валидации.
