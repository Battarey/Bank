# Redis Client (redis)

Модуль для высокопроизводительной работы с сессионными данными и временными хранилищами.

## Схема хранения сессий
Для управления доступом используются две структуры данных в Redis:
1.  **Hash** (`session:token:{token}`): Хранит данные сессии (`user_id`, `has_pin`, `phone`).
2.  **Set** (`session:user:{user_id}`): Список всех активных токенов пользователя для обеспечения функционала `Logout All`.

## Основные операции (`sessions.go`)
- **LoadToken**: Быстрое получение данных сессии для проверки в Middleware.
- **TouchToken**: Продление TTL (Time To Live) сессии при активности пользователя (скользящая экспирация).
- **RevokeAll**: Мгновенная аннуляция всех сессий пользователя (используется при блокировке аккаунта).

## Конфигурация
Клиент инициализируется через `REDIS_URL` из переменных окружения. Время жизни сессии по умолчанию — **30 минут**.
