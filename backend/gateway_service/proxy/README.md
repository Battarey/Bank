# Reverse Proxy (proxy)

Модуль для пересылки запросов от внешних клиентов во внутреннюю сеть микросервисов.

## Функционал (`forward.go`)

### 1. Forwarding (Проксирование)
- Принимает запросы от роутера Echo.
- Перенаправляет их в соответствующий внутренний сервис (Python/FastAPI) через стандартный `http.Client`.
- Поддерживает маппинг имен сервисов на внутренние URL (например, `auth` -> `http://auth_service:8001`).

### 2. Header Injection (Инъекция заголовков)
В целях безопасности прокси-слой автоматически модифицирует заголовки перед отправкой во внутреннюю сеть:
- **`X-Internal-Key`**: Добавляет секретный ключ для подтверждения того, что запрос пришел именно от шлюза.
- **`X-User-ID`**: Если пользователь авторизован, прокси извлекает его UUID из контекста сессии и пробрасывает дальше.
- **`Content-Type`**: Принудительно устанавливается в `application/json`.

## Обработка отказов (Resilience)
- **Timeout**: Установлен жесткий таймаут (30 секунд) на ожидание ответа от внутренних сервисов.
- **Bad Gateway**: Если внутренний сервис недоступен, прокси возвращает стандартную ошибку `502 Bad Gateway` в унифицированном формате.
