# Gateway Service (Go)

API Gateway банковской платформы — высокопроизводительная точка входа, реализованная на языке **Go**. Он объединяет все микросервисы в единый API, обеспечивая безопасность, маршрутизацию и управление состоянием сессий.

## Файловая архитектура
```
gateway_service/
├── main.go               # Запуск сервера и DI
├── config/               # Конфигурация из .env
├── middleware/           # Auth, PIN-gate, CORS
├── proxy/                # Логика Reverse Proxy
├── redis/                # Клиенты Redis/Redis Stack
├── routes/               # Обработчики (account, auth, customer и др.)
├── docs/                 # Swagger UI
├── Dockerfile            # Multi-stage сборка
└── go.mod                # Зависимости
```

## Технологический стек
-   **Язык**: Go 1.23
-   **Фреймворк**: Echo v4
-   **Хранилища**: Redis (Sessions), Redis Stack (Onboarding)
-   **Документация**: Swagger (автогенерация через `swag`)

## Безопасность и Проксирование

1.  **Аутентификация (X-Session-Token)**: Middleware проверяет наличие активной сессии в Redis. Поддерживается "скользящее" окно жизни токена (автопродление при активности).
2.  **Onboarding (X-Onboarding-Token)**: Специальный токен для незавершенных регистраций, ограничивающий доступ только к шагам онбординга.
3.  **PIN-gate**: Глобальная защита. Пользователи без установленного PIN-кода имеют доступ только к ограниченному набору методов (смена PIN, Logout).
4.  **Внутренняя авторизация**: При проксировании Gateway добавляет заголовок `X-Internal-Key` и `X-User-ID`, позволяя внутренним Python-сервисам доверять запросу.

## REST API v1

Все эндпоинты сгруппированы под префиксом `/api/v1`.

### Доступ и Сессии
| Метод  | Путь                         | Описание                                  |
|--------|------------------------------|-------------------------------------------|
| POST   | `/sessions`                  | Вход (создание сессии)                    |
| DELETE | `/sessions/current`          | Выход (текущее устройство)                |
| DELETE | `/sessions`                  | Выход со всех устройств                   |
| PUT    | `/pins`                      | Установить или сменить PIN-код            |

### Счета и Транзакции
| Метод  | Путь                         | Описание                                  |
|--------|------------------------------|-------------------------------------------|
| POST   | `/accounts`                  | Открыть новый счёт                        |
| GET    | `/accounts`                  | Список всех счетов пользователя           |
| DELETE | `/accounts/{id}`             | Закрыть счёт                              |
| POST   | `/accounts/{id}/suspensions` | Заморозить операции по счёту              |
| DELETE | `/accounts/{id}/suspensions` | Разморозить операции по счёту             |
| POST   | `/transactions`              | Финансовая операция (deposit/withdraw/transfer) |
| GET    | `/accounts/{id}/transactions`| История транзакций по счёту               |

### Профиль и KYC (Онбординг)
| Метод  | Путь                            | Описание                                  |
|--------|---------------------------------|-------------------------------------------|
| POST   | `/onboarding`                   | Начать регистрацию (выдача токена)        |
| POST   | `/onboarding/personal-data`     | Шаг 1: ФИО и дата рождения                |
| POST   | `/onboarding/passport`          | Шаг 2: Паспортные данные                  |
| POST   | `/onboarding/completion`        | Завершение и активация аккаунта           |
| PATCH  | `/customers/me/personal-data`   | Обновить персональные данные              |
| DELETE | `/customers/me`                 | Полное удаление аккаунта (Soft Delete)    |

## Структура Проекта
-   **`middleware/`**: Логика аутентификации и PIN-gate.
-   **`proxy/`**: Ядро проксирования запросов с обработкой заголовков.
-   **`routes/`**: Разделенные по доменам обработчики (auth, account, customer и др.).
-   **`redis/`**: Высокоуровневые клиенты для работы с сессиями и токенами.

## Запуск и Обновление
```bash
# Сборка и запуск
docker compose up -d gateway_service

# Генерация Swagger
swag init -g main.go
```
