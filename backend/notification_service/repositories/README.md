# Repositories Layer (MongoDB Log)

Слой доступа к данным для хранения истории уведомлений.

## Состав
- `notification.py` — Асинхронная работа с MongoDB (коллекция `email_log`).

## Особенности
- Использует `shared.mongodb_core` для работы с базой.
- Автоматически устанавливает индексы (включая TTL-индексы) при инициализации через воркер.
