# Services Layer (Notification Logic)

Слой бизнес-логики уведомлений.

## Состав
- `notification.py` — Логика обработки уведомления: рендеринг шаблона, отправка письма, логирование.
- `templates/` — Система шаблонов уведомлений (HTML + логика рендеринга).

## Особенности
- Координирует работу внешнего SMTP клиента и репозитория логов.
- Обрабатывает ошибки отправки и обеспечивает гарантированное логирование статуса.
