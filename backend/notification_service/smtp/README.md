# Модуль SMTP-транспорта (smtp)

Низкоуровневый асинхронный клиент для взаимодействия с почтовыми серверами.

## Функционал
- Поддержка протоколов SSL и TLS.
- Асинхронная отправка через `aiosmtplib`.
- Формирование корректных заголовков MIME (UTF-8).

## Конфигурация (Environment)
Настройка выполняется через переменные окружения:
- `SMTP_HOST`: Адрес почтового сервера.
- `SMTP_PORT`: Порт (по умолчанию 465 для SSL).
- `SMTP_USER`: Логин (Email).
- `SMTP_PASSWORD`: Пароль или токен приложения.
- `SMTP_FROM`: Отображаемое имя отправителя (поле From).
- `SMTP_USE_TLS`: Флаг использования защищенного соединения.

## Обработка ошибок
Если SMTP-сервер недоступен или учетные данные неверны, сервис логирует ошибку и возвращает сообщение в RabbitMQ для повторной попытки (Retry Policy), если это настроено в воркере.
