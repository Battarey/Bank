# Notification Service (Email Dispatcher)

Асинхронный воркер (RabbitMQ Consumer), отвечающий за доставку Email-уведомлений пользователям. Обеспечивает безопасность через использование строгих шаблонов и ведение детального журнала в NoSQL.

## Файловая архитектура
```
notification_service/
├── templates/            # Реестр и логика шаблонов
├── smtp/                 # Асинхронный транспорт
├── store/                # Клиент MongoDB
├── consumers.py          # Подписка на RMQ
├── service.py            # Подготовка писем
├── repository.py         # Сохранение журнала
├── main.py               # Точка входа
└── README.md
```

## Архитектура и Структура
Сервис реализует **4-слойную структуру воркера**:
-   **`consumers.py`**: Управление подпиской на Exchange `notifications` (Routing Key: `email.send`).
-   **`service.py`**: Бизнес-логика выбора шаблона и подготовки письма.
-   **`repository.py`**: Слой сохранения истории уведомлений в MongoDB.
-   **`smtp/`**: Асинхронный SMTP-клиент (транспортный слой).
-   **`templates/`**: Реестр и логика наполнения Email-шаблонов.

## Принцип работы

1.  Любой сервис (напр. `auth_service`) публикует событие в RabbitMQ.
2.  `Notification Service` получает сообщение, извлекает `type` (имя шаблона) и `payload`.
3.  Сервис проверяет наличие такого шаблона в реестре `TEMPLATES`.
4.  Письмо отправляется через SMTP (Gmail), а запись об операции сохраняется в MongoDB.

---

## Журнал Уведомлений (MongoDB)
Каждое отправленное письмо сохраняется в коллекции `email_log`.
-   **Статусы**: `sent` (успешно), `failed` (ошибка).
-   **TTL**: Автоматическое удаление записей через 90 дней (индекс на `created_at`).
-   **Аудит**: Позволяет проверить, было ли отправлено письмо конкретному пользователю и с какими данными.

## Популярные Шаблоны
-   `verification_code`: Код для подтверждения Email.
-   `welcome`: Приветствие при завершении онбординга.
-   `pin_changed`: Уведомление о смене PIN-кода.
-   `login_alert`: Предупреждение о новом входе в аккаунт.
-   `transaction_transfer`: Чек о совершенном переводе.
-   `security_freeze`: Уведомление о блокировке счета AML-системой.

---

## Особенности реализации
-   **Безопасность**: Произвольный текст письма отправить невозможно — только предопределенные шаблоны.
-   **Изоляция**: Если SMTP-сервер временно недоступен, сообщения остаются в очереди RabbitMQ для повторной обработки.
-   **Контроль**: Детальное логирование ошибок SMTP-транспорта.

## Технологии
-   **Python 3.12**: asyncio-стек.
