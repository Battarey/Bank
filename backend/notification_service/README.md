# Notification Service

Сервис автоматической рассылки уведомлений пользователям системы. Работает как фоновый потребитель (Consumer) событий из RabbitMQ, выполняя рендеринг писем и их отправку через SMTP.

## Файловая архитектура
```
notification_service/
├── consumers.py      # Обработчик очереди RabbitMQ (notifications_queue)
├── smtp/             # Асинхронный SMTP-клиент (aiosmtplib)
├── templates/        # Реестр и логика рендеринга шаблонов писем
├── main.py           # Точка входа (запуск воркера)
└── README.md
```

## Принцип работы

### 1. Потребление событий
Сервис слушает очередь `notifications_queue` (exchange `notifications.topic`). Ожидает сообщения в формате:
```json
{
    "type": "welcome",
    "payload": {
        "to": "user@example.com",
        "variables": { "name": "Иван" }
    }
}
```

### 2. Рендеринг (Templates)
По полю `type` подбирается соответствующий шаблон из реестра `templates/`. Плэйсхолдеры в теме и теле письма заменяются данными из `variables`.

### 3. Отправка (SMTP)
Сформированное MIME-сообщение отправляется получателю через асинхронный SMTP-транспорт.

## Поддерживаемые уведомления
- **Безопасность**: Коды подтверждения, уведомления о входе, смене PIN, блокировке/разблокировке аккаунта.
- **Счета**: Открытие, закрытие, заморозка и разморозка банковских счетов.
- **Транзакции**: Пополнение, списание, входящие и исходящие переводы.

## Технологии
- **Aio-pika**: Работа с RabbitMQ.
- **Aiosmtplib**: Асинхронный SMTP клиент.
- **Jinja2 / String Format**: Рендеринг текста писем.
