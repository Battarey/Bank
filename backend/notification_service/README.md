Системный микросервис для обеспечения коммуникации с пользователями. Отвечает за отправку Email-уведомлений, OTP-кодов и ведение архива отправленных сообщений.

## Архитектура

Сервис работает по принципу асинхронного воркера (Event Consumer) с HTTP-интерфейсом для мониторинга состояния.

```text
notification_service/
├── api/                # Эндпоинты Health Check
├── workers/            # Консьюмеры RabbitMQ: прием и маршрутизация уведомлений
├── services/           # Ядро: логика отправки (SMTP) и шаблонизация
├── repositories/       # Работа с MongoDB: хранение истории уведомлений
├── templates/          # Jinja2-шаблоны электронных писем
├── core/               # Инфраструктура: config, container
├── main.py             # Точка входа в приложение
└── README.md
```

## Как это работает

1.  **Слушатель**: Подписывается на очередь в RabbitMQ (Exchange: `notifications`).
2.  **Шаблонизация**: Входящие данные (variables) подставляются в HTML-шаблоны Jinja2.
3.  **Доставка**: Отправка через SMTP-шлюз (поддержка Gmail, Mail.ru и др. через SSL/TLS).
4.  **Архивация**: Каждое отправленное письмо сохраняется в MongoDB в коллекцию `notification_history` для разбора инцидентов и аудита.

## Обрабатываемые уведомления (Trigger Events)

Сервис обрабатывает события типа `NotificationEvent` из очереди.

| Тип уведомления (Variable) | Назначение                                  |
|----------------------------|---------------------------------------------|
| `email_verification`       | Ссылка или код подтверждения Email          |
| `welcome`                  | Приветствие после успешной регистрации      |
| `transaction_transfer`     | Уведомление о списании (перевод)            |
| `transaction_incoming`     | Уведомление о зачислении (перевод)          |
| `transaction_deposit`      | Уведомление о пополнении баланса            |
| `account_opened/closed`    | Жизненный цикл банковского счёта            |
| `pin_changed/unlocked`     | Изменение параметров безопасности           |

## Переменные окружения

| Ключ | Описание | Значение по умолчанию |
|------|----------|-----------------------|
| `APP_ENV` | Окружение (local, test, dev, prod) | `local` |
| `SMTP_HOST` | Адрес SMTP-сервера | - |
| `SMTP_USER` | Пользователь (login) для SMTP | - |
| `SMTP_PASSWORD` | Пароль (или пароль приложения) SMTP | - |
| `MONGO_URL` | Хранилище истории уведомлений | `mongodb://...` |
| `RABBITMQ_URL` | URL брокера | `amqp://...` |

## Технологии
- **Jinja2**: Движок шаблонов для Email-рассылок.
- **Aiosmtplib**: Асинхронный клиент для отправки Email.
- **MongoDB (Motor)**: Хранение истории без жесткой схемы.
- **RabbitMQ**: Источник входящих задач.
- **FastAPI**: Health-мониторинг воркера.
