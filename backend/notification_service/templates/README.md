# Реестр шаблонов уведомлений (NEXUS Digital Bank)

Централизованное хранилище всех типов сообщений в стиле **NEXUS Black Minimalism**.

## Технологический стек
- **Jinja2**: Используется для рендеринга динамического HTML-контента.
- **HTML/CSS**: Адаптивная верстка с темной темой (#121212).
- **Multipart/Alternative**: Письма отправляются одновременно в Text и HTML форматах.

## Структура шаблонов
- `base.html`: Базовый Layout (логотип NEXUS, шрифты, футер).
- `verification_code.html`: Коды подтверждения и разблокировки.
- `transaction.html`: Все операции по счету (списания, пополнения, переводы).
- `security_alert.html`: Оповещения о входе, смене PIN и блокировках.
- `account_status.html`: Открытие/закрытие счетов, заморозка.
- `welcome.html`: Приветственное письмо.

## Как добавить новый шаблон
1. Создайте HTML-файл в этой папке, расширяющий `base.html`: `{% extends "base.html" %}`.
2. Добавьте новый экземпляр `EmailTemplate` в `templates.py`, указав `html_template_name`.
3. Зарегистрируйте его в словаре `TEMPLATES`.

## Тестирование
Все шаблоны поддерживают автоматическую подстановку переменных через контекст Jinja2. При рендеринге в шаблон всегда передаются `subject` и `name` (внутреннее имя шаблона).
