# Реестр шаблонов уведомлений (templates)

Централизованное хранилище всех типов сообщений, отправляемых пользователям.

## Как работают шаблоны
Каждое уведомление состоит из темы (Subject) и тела (Body). В тексте используются плэйсхолдеры в формате `{variable_name}`, которые заполняются данными из события RabbitMQ.

## Список шаблонов и переменные

| Тип (Type)             | Тема письма                   | Переменные                                         |
|------------------------|-------------------------------|---------------------------------------------------|
| `welcome`              | Добро пожаловать!             | —                                                 |
| `verification_code`    | Код подтверждения             | `{code}`                                          |
| `login_alert`          | Вход в аккаунт                | `{login_time}`                                    |
| `transaction_transfer` | Перевод выполнен              | `{from_account}`, `{to_account}`, `{amount}`, ... |
| `account_frozen`       | Счёт заморожен                | `{account_number}`, `{reason}`                    |
| `account_unlocked`     | Доступ восстановлен           | —                                                 |

*Полный список доступен в файле `templates.py`.*

## Добавление нового шаблона
1. Определите новый экземпляр `EmailTemplate` в `templates.py`.
2. Зарегистрируйте его в словаре `TEMPLATES`.
3. Теперь любой микросервис может инициировать отправку этого письма, опубликовав событие с соответствующим `type`.
