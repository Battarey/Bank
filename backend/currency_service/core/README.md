# Core Layer

Инфраструктурный слой, содержащий конфигурацию, глобальные исключения и управление жизненным циклом транзакций.

## Состав
- `config.py`: Конфигурация сервиса (настройки БД, RabbitMQ, ключи внешних API).
- `uow.py`: Реализация `CurrencyUnitOfWork` для координации транзакций.
- `exceptions.py`: Доменные исключения (InsufficientFunds, RateUnavailable и др.).

## Особенности
- **Unit of Work**: Обеспечивает атомарность: либо списание и зачисление происходят успешно, либо вся транзакция откатывается.
- Автоматически подключает глобальные обработчики исключений в `main.py`.
