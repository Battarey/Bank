# API Layer (Routers)

Слой API отвечает за определение эндпоинтов FastAPI, валидацию входящих запросов через Pydantic-схемы и вызов соответствующих сервисов бизнес-логики.

## Состав
- `exchange.py`: Эндпоинты для проведения конверсионных операций между счетами.
- `rates.py`: Эндпоинты для получения актуальных курсов валют (всех или конкретной пары).

## Особенности
- Использует `shared.schemas` для унификации форматов данных.
- Проверяет `X-Internal-Key` и `X-User-ID` для обеспечения безопасности межсервисного взаимодействия.
