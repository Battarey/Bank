# Currency Service

Сервис обеспечения валютных операций: получение актуальных котировок, расчет кросс-курсов и выполнение конвертации между счетами пользователей.

## Архитектура
Сервис построен по принципам **Layered Architecture** (послойная архитектура) и строго следует 4-х слойной структуре (Routers, Services, Repositories, Core, Clients).

### Файловая структура
```text
currency_service/
├── api/                # Слой Routers: эндпоинты котировок и обмена
├── services/           # Слой Services: бизнес-логика валютных операций
├── repositories/       # Слой Repository: работа со счетами и транзакциями
├── core/               # Инфраструктурный слой: config, uow, exceptions
├── clients/            # Внешние клиенты: ExchangeRate-API
├── main.py             # Точка входа в приложение
├── tests/              # Юнит и интеграционные тесты
└── README.md
```

## Основной функционал
1.  **Мониторинг курсов**: Поддержка валютных пар RUB, USD, EUR.
2.  **Валютный обмен**: Безопасная конвертация средств между счетами с защитой от изменения баланса во время операции.
3.  **Аудит и уведомления**: Каждая операция обмена фиксируется в аудит-логе и отправляется как уведомление пользователю.

## Бизнес-правила
- **Точность**: Все расчеты проводятся с использованием типа `Decimal`, округление до `0.01`.
- **Безопасность**: Обмен возможен только между счетами одного владельца.
- **Транзакционность**: Использование паттерна Unit of Work гарантирует, что либо оба счета обновятся, либо ни один.

## 🛰 API Эндпоинты

Все запросы требуют заголовок `X-Internal-Key`.

| Метод | Путь                            | Описание                                  |
|-------|---------------------------------|-------------------------------------------|
| GET   | `/rates`                        | Текущие курсы ко всем валютам             |
| GET   | `/rates/{base}/{target}`        | Курс конкретной валютной пары             |
| POST  | `/currency-conversions`         | Обмен валют между счетами пользователя    |
| GET   | `/health`                       | Проверка состояния сервиса                |

## Технологии
- **FastAPI**: Фреймворк API.
- **PostgreSQL**: Хранение транзакций обмена.
- **RabbitMQ**: Публикация событий `transaction_transfer`.
- **Decimal**: Гарантия точности финансовых вычислений.
