# Currency Service

Сервис для работы с валютными курсами и проведения конверсионных операций между счетами пользователей. Обеспечивает актуальные данные котировок и атомарность обмена валют.

## Файловая архитектура
```
currency_service/
├── rates/                # Получение котировок
├── exchange/             # Конвертация между счетами
├── exchange_client.py    # Внешний API клиент
├── repository.py         # Репозиторий счетов
├── uow.py                # CurrencyUnitOfWork
├── main.py               # Точка входа
└── README.md
```

## Архитектура и Структура
Сервис следует 4-слойному паттерну:
-   **`rates/`**: Модуль получения котировок из внешних API.
-   **`exchange/`**: Модуль проведения конверсионных операций.
-   **`uow.py`**: Реализация `CurrencyUnitOfWork` для атомарных транзакций между счетами.
-   **`exchange_client.py`**: Клиент для интеграции с внешним провайдером курсов валют (ExchangeRate API).

## API Эндпоинты

Все запросы требуют заголовок `X-Internal-Key`.

| Метод | Путь                               | Описание                                  |
|-------|------------------------------------|-------------------------------------------|
| GET   | `/rates`                           | Получить таблицу курсов всех валют        |
| GET   | `/rates/{base}/{target}`           | Получить курс конкретной валютной пары    |
| POST  | `/currency-conversions`            | Обменять валюту между своими счетами      |

## Бизнес-правила

### Получение курсов
-   Данные запрашиваются у внешнего провайдера и кэшируются в памяти. 
-   **Кэширование**: 30 секунд для информационных запросов и 60 секунд для операций обмена.
-   Поддерживаемые валюты: `RUB`, `USD`, `EUR`.

### Конвертация средств
-   Операция возможна только между счетами, принадлежащими одному пользователю.
-   **Атомарность**: Списание с одного счета и зачисление на другой происходит в рамках одной транзакции БД через UoW.
-   **Row-Level Locking**: Оба счета блокируются (`FOR UPDATE`) на время проведения операции для предотвращения Race Conditions.

## Доменные события (Domain Events)

-   **`CurrencyExchanged`**: Сведения об операции для аудит-лога.
-   **`NotificationEvent`**: Триггерит уведомление пользователю об успешном обмене валюты.

## Технологии
-   **FastAPI**: API Framework.
-   **Httpx**: Асинхронный клиент для внешних API.
-   **SQLAlchemy 2.0**: Работа с БД счетов.
-   **RabbitMQ**: Доменные события и логирование.
