# Модуль курсов валют (rates)

Обеспечивает доступ к актуальным котировкам валют для внутренних нужд системы и отображения в интерфейсе.

## Файлы
- `router.py`: Эндпоинты `GET /rates` и `GET /rates/{base}/{target}`.
- `service.py`: Логика обработки и кеширования котировок.

## Основные операции

### 1. Получение всех курсов (`GET /rates`)
Возвращает список всех доступных котировок относительно базовой валюты (обычно RUB). Данные запрашиваются через `exchange_client` из внешнего доверенного источника или кеша.

### 2. Курс валютной пары (`GET /rates/{base}/{target}`)
Позволяет получить точный кросс-курс между двумя выбранными валютами.

## Доступные валюты
Система поддерживает следующие международные коды:
- **RUB**: Российский рубль (Базовая валюта системы).
- **USD**: Доллар США.
- **EUR**: Евро.

## Обработка ошибок
- `CurrencyNotAvailable` (404): Запрошенная валюта не поддерживается системой.
- `RateUnavailable` (502): Ошибка связи с поставщиком ликвидности/котировок.
