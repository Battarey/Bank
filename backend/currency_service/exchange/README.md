# exchange

Модуль обмена валюты между банковскими счетами (RUB/USD/EUR).

## Файлы

| Файл         | Назначение                                                              |
|--------------|-------------------------------------------------------------------------|
| `service.py` | `exchange()` — блокировка счетов, конвертация, создание транзакций      |
| `router.py`  | `POST /exchange`                                                        |

## Логика `exchange()`

1. Проверка: `from_account_id ≠ to_account_id`
2. `SELECT ... FOR UPDATE` на оба счёта (упорядоченная блокировка UUID для предотвращения deadlock)
3. Проверка принадлежности обоих счетов пользователю, статус `open`
4. Проверка: валюты счетов различаются
5. Получение актуального курса через `exchange_client.get_fresh_rate()`
6. Конвертация суммы: `to_amount = amount × rate` (ROUND_HALF_UP)
7. Проверка баланса счёта-источника
8. Обновление балансов, создание двух записей `Transaction(type=exchange)`
9. Уведомление через RabbitMQ

## Уведомления

После успешного обмена публикуется RabbitMQ-сообщение с информацией об операции.

## Исключения (из `currency_service.exceptions`)

| Класс                  | HTTP | Описание                                        |
|------------------------|------|-------------------------------------------------|
| `AccountNotFound`      | 404  | Счёт не найден или не принадлежит пользователю  |
| `AccountNotOpen`       | 409  | Статус счёта ≠ `open`                           |
| `SameAccountExchange`  | 409  | Попытка обмена на тот же счёт                   |
| `SameCurrencyExchange` | 409  | Валюты совпадают — обмен не нужен               |
| `InsufficientFunds`    | 422  | Недостаточно средств на счёте-источнике         |
| `RateUnavailable`      | 502  | Не удалось получить актуальный курс             |
