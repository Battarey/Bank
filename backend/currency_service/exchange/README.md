# Модуль обмена валют (exchange)

Реализует отказоустойчивый механизм конвертации средств между валютными счетами пользователя.

## Файлы
- `router.py`: Эндпоинт `POST /exchange`.
- `service.py`: Бизнес-логика транзакционного обмена и расчёта сумм.

## Механика обмена

### 1. Атомарность и блокировки
Для предотвращения race conditions и deadlock-ов используется строгий порядок блокировки:
- Оба счета (списания и зачисления) блокируются в БД через `SELECT ... FOR UPDATE`.
- Идентификаторы счетов предварительно сортируются перед блокировкой.

### 2. Правила конвертации
1.  **Проверка прав**: Оба счета должны принадлежать инициатору и иметь статус `open`.
2.  **Валидация валют**: Счета должны иметь разные валюты (для одинаковых используется обычный перевод).
3.  **Курс**: Используется мгновенный курс `get_fresh_rate` без скрытых комиссий.
4.  **Точность**: Сумма зачисления рассчитывается с округлением до 2-го знака (`0.01`) по правилу `ROUND_HALF_UP`.

### 3. Двойная запись (Transaction Accounting)
Операция обмена порождает две связанные транзакции:
- `outgoing` (списание) со счета А.
- `incoming` (зачисление) на счет Б.
Обе записи имеют общий `external_ref` (курс обмена) и тип `exchange`.

## Исключения
- `InsufficientFunds` (422): Сумма обмена превышает доступный остаток.
- `SameAccountExchange` (409): Попытка обмена в рамках одного счета.
- `AccountNotOpen` (409): Один из счетов заблокирован или закрыт.
