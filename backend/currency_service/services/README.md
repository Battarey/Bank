# Service Layer

Слой сервисов инкапсулирует бизнес-логику валютных операций. Он координирует работу внешних клиентов, репозиториев и Unit of Work.

## Состав
- `exchange.py`: Логика обмена валют (блокировка счетов, получение курса, расчет сумм, создание транзакций).
- `rates.py`: Логика получения и агрегации котировок от внешних провайдеров.

## Особенности
- **Атомарность**: Все операции изменения данных (обмен) выполняются внутри контекста `Unit of Work`.
- **Событийная модель**: Генерирует `LogEvent` для аудита и `NotificationEvent` для уведомления пользователей о результатах обмена.
- **Обработка ошибок**: Преобразует технические ошибки внешних API в доменные исключения.
