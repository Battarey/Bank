# Тестирование (tests)

Комплексная проверка точности финансовых расчётов и стабильности обмена валют.

## Структура тестов
- `/unit`: Изолированная проверка логики округления сумм и валидации запросов.

## Ключевые проверки
- **Math Precision**: Проверка отсутствия потерь точности при многократных конвертациях.
- **Race Condition**: Тестирование блокировок `FOR UPDATE` при параллельных попытках обмена.
- **EDA Check**: Убеждаемся, что уведомление об обмене формируется только после успешного коммита в БД.

## Запуск тестов
```powershell
docker compose run --rm -e APP_ENV=test currency_service sh -c "pip install --no-cache-dir -r shared/requirements-test.txt && pytest currency_service/tests/unit -v"
```
