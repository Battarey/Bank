# Clients Layer

Слой внешних клиентов для взаимодействия со сторонними API и сервисами.

## Состав
- `exchange_client.py`: Асинхронный клиент для взаимодействия с API курсов валют (ExchangeRate-API).

## Особенности
- **Кэширование**: Реализовано встроенное кэширование котировок (TTL настраивается через переменные окружения).
- **Отказоустойчивость**: Обработка сетевых ошибок и таймаутов внешнего API.
- Использует `httpx` для асинхронных HTTP-запросов.
