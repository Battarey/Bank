# API Layer (Routers)

Этот слой содержит определения эндпоинтов FastAPI и логику диспетчеризации запросов для сервиса аутентификации.

## Ответственность
- Определение путей (routes) и методов (GET, POST и т.д.) для входа, сессий и разблокировки.
- Валидация входящих данных через Pydantic-схемы.
- Интеграция с зависимостями авторизации (require_user_id).
- Вызов соответствующих методов из слоя `services`.
- Формирование итогового HTTP-ответа.

## Файлы
- `login.py`: Роутер для аутентификации по PIN-коду и установки PIN.
- `session.py`: Управление активными сеансами и самоблокировка аккаунта.
- `unlock.py`: Восстановление доступа через Email-коды.
