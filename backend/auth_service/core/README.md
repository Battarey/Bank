# Core Layer (Infrastructure)

Ядро сервиса, содержащее общую инфраструктурную логику, настройки и базовые компоненты.

## Ответственность
- Реализация паттерна Unit of Work (`uow.py`) для обеспечения атомарности операций аутентификации.
- Определение иерархии бизнес-исключений (`exceptions.py`) для корректной обработки ошибок (SIP/PIN-errors, cooldowns).
- Предоставление общих утилит для работы с сессиями и шифрованием.

## Файлы
- `uow.py`: Реализация AuthUnitOfWork.
- `exceptions.py`: Глобальные исключения сервиса аутентификации.
