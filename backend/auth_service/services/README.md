# Service Layer

Слой бизнес-логики, оркестрирующий выполнение всех операций аутентификации, управления сессиями и разблокировки.

## Ответственность
- Описание правил аутентификации (проверка PIN, хеширование).
- Оркестрация работы репозиториев, Redis и Unit of Work.
- Управление событиями уведомлений (коды разблокировки, смена PIN) и логов аудита.
- Реализация Rate-limit логики для предотвращения подбора паролей.

## Файлы
- `login.py`: Бизнес-логика входа по PIN-коду и первичной аутентификации.
- `session.py`: Логика управления сессиями и самоблокировки аккаунта.
- `unlock.py`: Логика восстановления доступа через Email-верификацию.
