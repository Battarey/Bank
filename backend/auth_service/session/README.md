# Модуль управления сессиями (session)

Управляет активными сеансами пользователя и безопасностью учетных данных (PIN).

## Файлы
- `router.py`: Эндпоинты `/pins`, `/sessions/current` (Logout), `/sessions` (Logout All).
- `service.py`: Логика хеширования PIN и отзыва токенов в Redis.

## Основные операции

### 1. Управление PIN-кодом (`PUT /pins`)
- Принимает 4-6 значный цифровой код.
- Выполняет хеширование с использованием уникальной соли через `bcrypt`.
- Генерирует событие `pin_changed` для уведомления по Email.

### 2. Завершение сеанса (Logout)
- `DELETE /sessions/current`: Удаляет только текущий токен запроса из Redis.
- `DELETE /sessions`: (Logout All) Рекурсивно находит и удаляет все активные сессии пользователя во всех браузерах/устройствах.

### 3. Самоблокировка аккаунта (`POST /sessions/me/block`)
Позволяет пользователю мгновенно:
- Установить статус аккаунта в `blocked`.
- Вызвать каскадную заморозку всех банковских счетов.
- Отозвать все активные сессии.

## Очередь событий
Все изменения статуса и безопасности проходят через `AuthUnitOfWork` и фиксируются в аудит-логе.
