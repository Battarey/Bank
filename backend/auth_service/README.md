# Auth Service

Микросервис аутентификации и управления сессиями. Отвечает за вход по PIN-коду, безопасность аккаунтов, блокировку и восстановление доступа.

## Файловая архитектура
```
auth_service/
├── login/                # Модуль входа и PIN
├── session/              # Управление сессиями и блокировка
├── unlock/               # Разблокировка аккаунта
├── repository.py         # Репозиторий пользователя
├── uow.py                # AuthUnitOfWork
├── main.py               # Точка входа
└── README.md
```

## Архитектура и Структура
Сервис следует 4-слойному паттерну:
-   **`login/`**, **`session/`**, **`unlock/`**: Доменные модули, разделенные по функциональности.
-   **`uow.py`**: Реалзация `AuthUnitOfWork` для работы с БД и RabbitMQ.
-   **`repository.py`**: Работа с сущностями пользователей и данных безопасности.
-   **`shared/redis_sessions`**: Используется для хранения активных токенов (сессий).

## 🛰 API Эндпоинты

Все запросы требуют заголовок `X-Internal-Key`.

| Метод  | Путь                         | Описание                                  |
|--------|------------------------------|-------------------------------------------|
| POST   | `/sessions`                  | Вход (телефон + PIN) -> Выдача токена     |
| DELETE | `/sessions/current`          | Выход (Logout текущей сессии)             |
| DELETE | `/sessions`                  | Сброс всех активных сессий пользователя   |
| PUT    | `/pins`                      | Установка или изменение PIN-кода          |
| POST   | `/sessions/me/block`         | Самоблокировка аккаунта                   |
| POST   | `/unlock-codes`              | Запросить 6-значный код для разблокировки |
| POST   | `/unlock-codes/verifications`| Подтвердить разблокировку по коду         |

## 🛡 Безопасность и Лимиты

-   **PIN**: Хранится в захешированном виде (bcrypt). 
-   **Сессии**: Токены хранятся в Redis с TTL (30 минут, скользящая экспирация).
-   **Rate-Limiting**: 5 неудачных попыток ввода PIN ведут к временной блокировке (5 мин). 15 попыток подряд — к полной блокировке аккаунта.
-   **Самоблокировка**: При вызове `/sessions/me/block` аккаунт переходит в статус `blocked`, все сессии отзываются, а счета в `account_service` замораживаются.

## 📡 Доменные события (Domain Events)

-   **`LoginSucceeded` / `LoginFailed`**: Для аудита безопасности и мониторинга попыток входа.
-   **`PinChanged`**: Триггерит уведомление пользователю о смене пароля.
-   **`AccountLocked`**: Публикуется при достижении лимита попыток или самоблокировке.
-   **`AccountUnlocked`**: Публикуется после успешного подтверждения кода разблокировки.

## 🛠 Технологии
-   **FastAPI**: API Framework.
-   **Redis**: Хранилище сессий и счетчиков попыток.
-   **SQLAlchemy 2.0**: Работа с БД.
-   **Bcrypt**: Хеширование PIN-кодов.
-   **RabbitMQ**: Доменные события.
