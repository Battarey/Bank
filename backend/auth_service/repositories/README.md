# Repository Layer

Слой доступа к данным, отвечающий за выполнение запросов к базе данных для проверки полномочий и статусов.

## Ответственность
- Выполнение специализированных запросов поиска пользователей (по хешам телефонов и email).
- Управление статусами аккаунтов (блокировка/активация).
- Проверка состояний счетов при каскадных заморозках/разморозках.
- Сокрытие деталей реализации SQLAlchemy от слоев бизнес-логики.

## Файлы
- `auth.py`: Основной репозиторий для аутентификации и управления состоянием пользователя.
