# Модуль разблокировки аккаунта (unlock)

Процедура восстановления доступа к аккаунту после блокировки из-за превышения лимитов безопасности.

## Файлы
- `router.py`: Эндпоинты `/unlock-codes` (запрос и подтверждение).
- `service.py`: Генерация временных кодов и сброс статуса блокировки.

## Механика восстановления
1.  **Запрос**: На эндпоинт передается Email. Система проверяет, что аккаунт заблокирован.
2.  **Генерация**: Создается случайный 6-значный цифровой код.
3.  **Хранение**: Код сохраняется в Redis с коротким TTL (10 минут).
4.  **Уведомление**: Отправляется событие `unlock_code` в RabbitMQ для доставки письма пользователю.
5.  **Подтверждение**: Пользователь вводит код. Сверка выполняется через `hmac.compare_digest` для защиты от timing-атак.
6.  **Результат**: Статус аккаунта меняется на `active`, счетчики неудачных попыток в Redis полностью сбрасываются.

## Исключения
- `UnlockInvalidCode` (400): Код неверен или срок его действия истек.
- `UnlockNotBlocked` (409): Попытка разблокировать уже активный аккаунт.
