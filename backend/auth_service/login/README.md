# Модуль входа (login)

Реализует первичную аутентификацию пользователя по номеру телефона и PIN-коду с защитой от перебора (brute-force).

## Файлы
- `router.py`: Эндпоинты `/sessions` (создание сессии).
- `service.py`: Валидация PIN, проверка статуса аккаунта и управление лимитами.

## Алгоритм аутентификации
1.  **Rate-limit**: Проверка количества неудачных попыток в Redis перед началом сверки PIN.
2.  **Поиск**: Нахождение пользователя по маскированному номеру телефона.
3.  **Безопасность**: Сверка PIN через `bcrypt.checkpw`. Используется медленное хеширование для защиты от атак.
4.  **Сессия**: При успехе генерируется криптографически стойкий `session_token` (через `secrets`), который сохраняется в Redis с TTL 30 минут (скользящая экспирация).

## Механизм защиты (Rate-limiting)
- **Кулдаун**: Каждые 5 неверных вводов активируют блокировку на 5 минут.
- **Блокировка аккаунта**: Если суммарное количество неудач превышает критический порог (15), аккаунт переходит в статус `blocked`.
- **Сброс**: Любой успешный вход полностью обнуляет счетчики неудач в Redis.

## События
- `login_failure`: Логируется при каждой 5-й неудачной попытке.
- `login`: Логируется при успешном входе.
- `login_alert`: Отправка Email-уведомления пользователю о новом входе в систему.
