# База данных и Миграции (Migrations)

Централизованный сервис управления схемой реляционной базы данных PostgreSQL с использованием Alembic. Гарантирует целостность структуры данных во всех сервисах системы.

## Файловая архитектура
```
migrations/
├── alembic/              # Конфигурация и скрипты миграций
│   ├── versions/         # История изменений схемы (ревизии)
│   └── env.py            # Настройка окружения и импорт моделей
├── alembic.ini           # Глобальный конфиг Alembic
├── reset_and_upgrade.py  # Скрипт полной переинициализации (Dev)
├── Dockerfile            # Контейнер для авто-миграций при деплое
└── README.md
```

## Рабочий процесс (Workflow)

### 1. Создание новой миграции
После изменения моделей в `shared/models/`, необходимо сгенерировать файл ревизии:
```powershell
alembic revision --autogenerate -m "описание_изменений"
```

### 2. Применение миграций
Для обновления базы данных до последней версии (HEAD):
```powershell
alembic upgrade head
```

### 3. Откат изменений
Для отката на одну версию назад:
```powershell
alembic downgrade -1
```

## Правила именования
Все миграции должны иметь осмысленные префиксы и краткое описание в названии файла, например: `2024_03_01_add_index_to_accounts.py`.

## Автоматизация в Docker
Контейнер `migrations` автоматически запускает команду `upgrade head` при старте. Это гарантирует, что микросервисы (Account, Auth, Customer) всегда работают с актуальной структурой БД при обновлении системы.

## Технологии
- **Alembic**: Инструмент миграций для SQLAlchemy.
- **SQLAlchemy 2.0**: Декларативные модели данных.
- **Shared Models**: Единый источник истины для схемы БД (находится в `backend/shared/models`).
