# Инфраструктура Alembic (alembic)

Внутренняя логика работы с ревизиями базы данных.

## Состав директории
- `env.py`: Главный файл настройки, который связывает SQLAlchemy-движок с Alembic. Здесь происходит импорт `target_metadata` из `shared.models`.
- `script.py.mako`: Шаблон, на основе которого генерируются файлы новых миграций.
- `versions/`: Хранилище всех файлов ревизий. Каждая ревизия содержит `upgrade()` и `downgrade()` логику.

## Интеграция с Shared Models
Для корректной работы автогенерации миграций (`--autogenerate`), в `env.py` импортируются все модели системы через:
```python
from shared.models.base import Base
target_metadata = Base.metadata
```
Это позволяет Alembic "видеть" изменения полей, добавление таблиц или индексов во всех микросервисах одновременно.

## Особенности
В файлах миграций могут присутствовать специфические SQL-команды для создания индексов ClickHouse или настройки PII-шифрования (если они затрагивают схему PostgreSQL).
