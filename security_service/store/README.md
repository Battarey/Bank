# store

MongoDB-журнал событий безопасности — хранение срабатываний AML-правил.

## Файлы

| Файл        | Назначение                                                            |
|-------------|-----------------------------------------------------------------------|
| `client.py` | Async MongoDB клиент: подключение, отключение, запись событий         |

## Функции

| Функция        | Описание                                                          |
|----------------|-------------------------------------------------------------------|
| `init_mongo()` | Подключение к MongoDB, создание TTL-индекса на коллекции          |
| `close_mongo()`| Закрытие соединения                                               |
| `save_event()` | Сохранение события безопасности (срабатывание правила)            |

## Хранение

- **Коллекция**: `security_events`
- **TTL**: 365 дней (автоудаление по полю `created_at`)
- **Подключение**: URL из переменной окружения `MONGO_URL`

## Структура документа

| Поле          | Тип        | Описание                                  |
|---------------|------------|-------------------------------------------|
| `account_id`  | `str`      | UUID счёта                                |
| `rule`        | `str`      | Имя сработавшего правила                  |
| `details`     | `dict`     | Подробности: суммы, количества, тип       |
| `action`      | `str`      | Предпринятое действие (freeze, reject)    |
| `threshold`   | `str/null` | Пороговое значение правила                |
| `actual`      | `str/null` | Фактическое значение                      |
| `created_at`  | `datetime` | Время события (UTC)                       |

## Жизненный цикл

`init_mongo()` вызывается в `lifespan` приложения (`main.py`) при старте, `close_mongo()` — при завершении.
