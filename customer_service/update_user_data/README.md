# Update User Data

Модуль обновления личных данных для активных пользователей.

## Файловая архитектура
```
update_user_data/
├── router.py                # FastAPI эндпоинты, зависимость require_user_id
├── service.py               # Бизнес-логика, проверка уникальности, нормализация
└── README.md
```

## Эндпоинты

| Метод | Путь                  | Описание                                    |
|--------|------------------------|--------------------------------------------|
| PATCH  | `/users/personal-data` | Частичное обновление ФИО (дата рождения и пол неизменяемы) |
| PUT    | `/users/passport`      | Полная замена паспортных данных                |
| PATCH  | `/users/contacts`      | Частичное обновление телефона / email          |

## Ограничения
- Доступно только для пользователей со статусом `active`
- `birth_date` и `gender` нельзя изменить после онбординга
- Пустой PATCH (ни одно поле не передано) → `422`
- Новый телефон / email / серия+номер паспорта проверяются на уникальность
- `user_id` поступает из заголовка `X-User-ID` (пробрасывается gateway)
