# Функционал для работы с банковским аккаунтом

 Здесь находится функионал создания, удаления банковского аккаунта, а так же обновления данных.

## Файловая архитектура
```
user_account
├── create_account/                # Создание банковского аккаунта
├── delete_account/                # Удаление банковского аккаунта
├── tests/
├── update_user_data/              # Обновление личных данных пользователя
└── README.md
```
