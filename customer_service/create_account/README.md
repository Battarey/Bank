# Create Account (онбординг)

Модуль создания аккаунта через пошаговый онбординг.

## Файловая архитектура
```
create_account/
├── router.py                # FastAPI эндпоинты, обработка HTTP-ошибок
├── service.py               # Бизнес-логика, валидация, нормализация данных
└── README.md
```

## Шаги онбординга

1. **Start** — создание пользователя со статусом `pending`
2. **Personal data** — ФИО, дата рождения, пол
3. **Passport** — серия, номер, кем/когда выдан, код подразделения, место рождения
4. **Identifiers** — ИНН (уникальный), СНИЛС (уникальный)
5. **Contacts** — телефон (уникальный), email (уникальный)
6. **Finalize** — перенос черновиков из Redis в PostgreSQL, статус → `active` + отправка welcome email

## Поток данных

```
Шаги 2—5: payload → нормализация → проверка уникальности → Redis (JSON)
Шаг 6:     Redis → чтение всех черновиков → PostgreSQL → очистка Redis
```

## Нормализация

Базовые функции нормализации вынесены в `shared/utils/normalize.py` и переиспользуются в `update_user_data`.

| Поле              | Правило                                 |
|-------------------|-----------------------------------------|
| ФИО               | `normalize_name()` — `.strip().upper()` |
| email             | `normalize_email()` — `.lower()`        |
| Телефон           | `normalize_phone()` — удаление пробелов |
| ИНН / СНИЛС       | `digits_only()` — только цифры          |
| Паспорт (текст)   | `.strip()`                              |
