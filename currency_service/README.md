# Currency Service

Внутренний сервис валютных операций. Предоставляет курсы валют и обмен между существующими счетами (RUB/USD/EUR). Курсы получаются через ExchangeRate API, ничего не сохраняется в БД.

## Структура

```
currency_service/
├── main.py              # Точка входа FastAPI, подключение роутеров
├── exchange_client.py   # Клиент ExchangeRate API, кэширование
├── exceptions.py        # Исключения сервиса
├── rates/               # Модуль просмотра курсов валют
├── exchange/            # Модуль обмена валюты между счетами
├── tests/               # Тесты
├── Dockerfile
└── requirements.txt
```

## Функциональность

### Просмотр курсов
- `GET /rates?base=RUB` — все курсы валют относительно базовой
- `GET /rates/{base}/{target}` — курс конкретной пары

### Обмен между счетами (RUB ↔ USD ↔ EUR)
- `POST /exchange` — конвертация валюты между двумя банковскими счетами пользователя

## Актуальность курса

- In-memory кэш с TTL 30 сек для просмотра курсов
- При обмене — принудительное обновление если данные старше 60 сек
- Ответ включает `last_updated` для прозрачности

## Переменные окружения

| Переменная               | Описание                    |
|--------------------------|-----------------------------|
| `DATABASE_URL`           | PostgreSQL                  |
| `INTERNAL_API_KEY`       | Ключ внутренней авторизации |
| `RABBITMQ_URL`           | RabbitMQ                    |
| `EXCHANGE_RATE_API_KEY`  | API-ключ ExchangeRate       |
| `EXCHANGE_RATE_BASE_URL` | Базовый URL API             |
