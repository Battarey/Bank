# rates

Модуль просмотра курсов валют.

## Файлы

| Файл         | Назначение                                                           |
|--------------|----------------------------------------------------------------------|
| `service.py` | `get_all_rates()`, `get_pair_rate()` — получение курсов из API       |
| `router.py`  | `GET /rates`, `GET /rates/{base}/{target}`                           |

## Логика `get_all_rates()`

Запрашивает все курсы для базовой валюты через `exchange_client.get_rates()`.

## Логика `get_pair_rate()`

1. Запрашивает все курсы для базовой валюты
2. Извлекает курс конкретной целевой валюты из ответа
3. Если целевая валюта отсутствует → `CurrencyNotAvailable`

## Исключения (из `currency_service.exceptions`)

| Класс                  | HTTP | Описание                                |
|------------------------|------|-----------------------------------------|
| `CurrencyNotAvailable` | 404  | Валюта не найдена в ответе API          |
| `RateUnavailable`      | 502  | Не удалось получить курсы из API        |
