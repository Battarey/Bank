# history

Модуль истории операций по банковскому счёту.

## Файлы

| Файл         | Назначение                                                            |
|--------------|-----------------------------------------------------------------------|
| `service.py` | `list_transactions()` — построение запроса с фильтрами, подсчёт total |
| `router.py`  | `GET /accounts/{id}/transactions` — эндпоинт с пагинацией             |

## Параметры запроса

| Параметр    | Тип    | По умолчанию | Описание                                |
|-------------|--------|--------------|-----------------------------------------|
| `limit`     | int    | 20           | Записей на странице (1–100)             |
| `offset`    | int    | 0            | Смещение                                |
| `type`      | string | —            | Фильтр: deposit / withdrawal / transfer |
| `direction` | string | —            | Фильтр: incoming / outgoing             |

## Ответ

```json
{
  "transactions": [...],
  "total": 42,
  "limit": 20,
  "offset": 0
}
```
