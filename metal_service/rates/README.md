# rates

Модуль просмотра цен на драгоценные металлы.

## Файлы

| Файл         | Назначение                                                         |
|--------------|--------------------------------------------------------------------|
| `service.py` | `get_all_prices()` — получение цен из Metals.Dev API               |
| `router.py`  | `GET /metals/rates`                                                |

## Логика `get_all_prices()`

Запрашивает цены на XAU, XAG, XPT, XPD за грамм в указанной валюте через `metal_client.get_metal_prices()`.

## Исключения (из `metal_service.exceptions`)

| Класс             | HTTP | Описание                                   |
|-------------------|------|--------------------------------------------|
| `RateUnavailable` | 502  | Не удалось получить цены из Metals.Dev API |
