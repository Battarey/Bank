# Account Service

Микросервис управления банковскими счетами: открытие, просмотр, закрытие, заморозка и разморозка. Работает только через Gateway (защита `X-Internal-Key`).

При операциях со счетами отправляет уведомления через RabbitMQ (шаблоны `account_opened`, `account_closed`, `account_frozen`, `account_unfrozen`) и публикует бизнес-события в exchange `logs` (routing key `log.account`) для аудит-лога и аналитики.

## Файловая архитектура
```
account_service/
├── open_account/            # Открытие счёта, список, детали
├── close_account/           # Закрытие счёта

├── tests/
├── exceptions.py            # Единая иерархия исключений
├── main.py
├── Dockerfile

└── README.md
```

## Эндпоинты

Все эндпоинты требуют заголовки `X-Internal-Key` и `X-User-ID`.

| Метод  | Путь                           | Код  | Описание                                 |
|--------|--------------------------------|------|------------------------------------------|
| POST   | `/accounts`                    | 201  | Открыть новый счёт                       |
| GET    | `/accounts`                    | 200  | Список всех счетов пользователя          |
| GET    | `/accounts/{account_id}`       | 200  | Детали конкретного счёта                 |
| POST   | `/accounts/{account_id}/close` | 200  | Закрыть счёт (баланс должен быть 0)      |
| POST   | `/accounts/{account_id}/freeze` | 200  | Заморозить счёт (frozen_by=user)    |
| POST   | `/accounts/{account_id}/unfreeze` | 200  | Разморозить счёт (только user-frozen) |

## Бизнес-правила

### Открытие счёта
- Пользователь должен быть в статусе `active`
- **Лимит:** максимум 3 открытых счёта на комбинацию `тип + валюта`
- Начальный баланс: `0.00`
- Генерируется уникальный 20-значный номер счёта

### Номер счёта (20 цифр)
```
TTTTTCCCКBBBBNNNNNNN
│     │  │ │    └── индивидуальный номер (7 цифр, случайный)
│     │  │ └─────── код отделения (4 цифры: 0001)
│     │  └───────── контрольная цифра (1 цифра)
│     └──────────── код валюты (3 цифры)
└────────────────── код балансового счёта (5 цифр)
```

**Коды типов:** `40817` (checking), `42301` (savings), `45505` (credit), `42305` (deposit)
**Коды валют:** `810` (RUB), `840` (USD), `978` (EUR)

### Типы счетов

| Тип         | Код   | Описание         |
|-------------|-------|------------------|
| `checking`  | 40817 | Расчётный счёт   |
| `savings`   | 42301 | Накопительный    |
| `credit`    | 45505 | Кредитный        |
| `deposit`   | 42305 | Вклад            |

### Закрытие счёта
- Счёт должен принадлежать пользователю
- Статус должен быть `open`
- Баланс должен быть `0.00` — иначе ошибка с указанием остатка
- При закрытии: `status → closed`, `closed_at → now(UTC)`

### Заморозка / разморозка
- **Заморозка:** статус `open` → `frozen`, сохраняется `frozen_by`, `frozen_at`, `freeze_reason`
- **Разморозка:** только для `frozen_by=user` (системную заморозку пользователь снять не может)
- **Каскадная заморозка:** при блокировке аккаунта все `open`-счета замораживаются (`frozen_by=system`)
- **Каскадная разморозка:** при разблокировке размораживаются только системные заморозки
- Soft-freeze: входящие операции разрешены, исходящие заблокированы

## Обработка ошибок

| Код  | Когда                                              |
|------|----------------------------------------------------|
| 400  | Некорректный тип/валюта, пользователь не активен   |
| 401  | Невалидный `X-Internal-Key`                        |
| 403  | Отсутствует `X-User-ID` / попытка разморозить системную заморозку |
| 404  | Счёт не найден / не принадлежит пользователю       |
| 409  | Лимит счетов, ненулевой баланс, статус ≠ open, уже заморожен / не заморожен |
