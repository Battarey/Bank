# open_account

Модуль открытия банковского счёта, списка и просмотра деталей.

## Файлы

| Файл         | Назначение                                                                 |
|--------------|----------------------------------------------------------------------------|
| `service.py` | `open_account()`, `list_accounts()`, `get_account()`, генерация номера     |
| `router.py`  | FastAPI-эндпоинты: `POST /accounts`, `GET /accounts`, `GET /accounts/{id}` |

## Логика `open_account()`

1. Проверка пользователя: существует, `status == "active"`
2. Подсчёт открытых счетов данного типа + валюты → лимит 3
3. Генерация уникального 20-значного номера (до 10 попыток)
4. Создание записи `BankAccount`: `balance=0`, `status=open`, `opened_at=now(UTC)`

## Логика `list_accounts()`

Возвращает все счета пользователя (любого статуса), отсортированные по `opened_at DESC`.

## Логика `get_account()`

Возвращает один счёт по `account_id`. Проверяет принадлежность (`client_id == user_id`).

## Уведомления

После успешного открытия публикуется RabbitMQ-сообщение `account_opened` с переменными `{account_type}`, `{currency}`, `{account_number}`.

## Исключения (из `account_service.exceptions`)

| Класс                  | HTTP | Описание                                         |
|------------------------|------|--------------------------------------------------|
| `AccountOwnerNotFound` | 400  | Пользователь не найден или не активен            |
| `AccountLimitReached`  | 409  | Превышен лимит (3 счёта на тип+валюту)           |
| `AccountNotFound`      | 404  | Счёт не найден                                   |
| `AccountConflict`      | 409  | Конфликт целостности (дубликат номера и т.д.)    |
| `AccountError`         | 400  | Базовая ошибка                                   |
