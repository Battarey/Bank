# close_account

Модуль закрытия банковского счёта.

## Файлы

| Файл         | Назначение                                     |
|-------------|------------------------------------------------|
| `service.py` | `close_account()` — бизнес-логика закрытия     |
| `router.py`  | `POST /accounts/{account_id}/close`            |

## Логика `close_account()`

1. Получение счёта по `account_id`
2. Проверка принадлежности: `client_id == user_id`
3. Проверка статуса: только `open` → можно закрыть
4. Проверка баланса: `balance == 0.00` (иначе — ошибка с суммой остатка)
5. Обновление: `status → "closed"`, `closed_at → now(UTC)`

## Уведомления

После успешного закрытия публикуется RabbitMQ-сообщение `account_closed` с переменной `{account_number}`.

## Исключения (из `account_service.exceptions`)

| Класс                  | HTTP | Описание                                        |
|------------------------|------|--------------------------------------------------|
| `AccountNotFound`      | 404  | Счёт не найден или не принадлежит пользователю  |
| `AccountNotOpen`       | 409  | Статус ≠ `open` (уже закрыт/заморожен)          |
| `AccountNonZeroBalance`| 409  | Баланс > 0 — нужно сначала вывести средства     |
| `AccountConflict`      | 409  | Конфликт при обновлении данных                   |
