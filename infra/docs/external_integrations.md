# Внешние интеграции (Third-party APIs)

Банковское приложение взаимодействует с несколькими внешними сервисами для получения рыночных данных и отправки уведомлений.

## 1. Metals.Dev API (Metal Service)
Используется для получения актуальных котировок драгоценных металлов.

- **Назначение:** Цены на Золото (XAU), Серебро (XAG), Платину (XPT) и Палладий (XPD).
- **Конечная точка:** `https://api.metals.dev/v1/latest`
- **Параметры:** `unit=g` (цена за грамм), `currency=RUB` (или указанная пользователем).
- **Кэширование:** In-memory кэш на 30 секунд.
- **API Key:** Параметр `api_key` в URL.

## 2. ExchangeRate API (Currency Service)
Используется для конвертации валют и отображения курсов (RUB, USD, EUR).

- **Назначение:** Кросс-курсы валют для операций обмена и переводов.
- **Конечная точка:** `https://v6.exchangerate-api.com/v6/{api_key}/latest/RUB`
- **Кэширование:** 
  - 30 секунд — для простого просмотра курсов.
  - 60 секунд — принудительное обновление перед финансовой операцией (обмен).

## 3. Gmail SMTP (Notification Service)
Используется как транспорт для отправки Email-уведомлений.

- **Хост:** `smtp.gmail.com`
- **Порт:** `465` (SSL/TLS)
- **Аутентификация:** Требуется **App Password** (Пароль приложения) от Google аккаунта.
- **Библиотека:** `aiosmtplib` (асинхронный SMTP).

### Настройка для разработки:
Для тестирования в `dev`-окружении можно использовать **Mailtrap** или **Mailhog**, изменив соответствующие `SMTP_HOST` и `SMTP_PORT` в переменных окружения.
