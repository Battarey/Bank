# Auth Service

Сервис аутентификации: вход по PIN-коду, управление сессиями, установка PIN, rate-limiting и разблокировка аккаунта.

## Файловая архитектура
```
auth_service/
├── login/                       # Вход по PIN-коду (+ rate-limit)
├── session/                     # Управление сессиями и PIN-кодом
├── unlock/                      # Разблокировка аккаунта по email-коду
├── main.py                      # Точка входа: lifespan (Redis + RabbitMQ), роутеры
├── Dockerfile
├── requirements.txt
└── README.md
```

## Эндпоинты

| Метод  | Путь               | Защита           | Описание                                       |
|--------|---------------------|-----------------|------------------------------------------------|
| POST   | `/login-pin`        | Публичный       | Вход по телефону + PIN → session-токен         |
| POST   | `/set-pin`          | X-User-ID       | Установка / смена PIN-кода                     |
| POST   | `/logout`           | X-Session-Token | Завершение текущего сеанса                     |
| POST   | `/logout-all`       | X-User-ID       | Завершение всех сеансов пользователя           |
| POST   | `/request-unlock`   | Публичный       | Отправка кода разблокировки на email           |
| POST   | `/unlock`           | Публичный       | Проверка кода и разблокировка аккаунта         |

## Поток аутентификации

### Первый вход (после онбординга)

```
Онбординг → finalize → gateway автоматически выдаёт session_token
                                  ↓
                        Пользователь устанавливает PIN
                        POST /set-pin { pin: "1234" }
                                  ↓
                        bcrypt.hashpw() → users.pin_hash
```

### Повторный вход (с rate-limiting)

```
POST /login-pin { phone, pin }
         │
         ▼
  Поиск пользователя по телефону (status = "active" или "blocked")
         │
         ├── status = "blocked" → 423 Locked
         │
         ├── Кулдаун активен? → 429 Too Many Requests (Retry-After)
         │
         ▼
  bcrypt.checkpw(pin, pin_hash)
         │
         ├── Неверный PIN:
         │     ├── Попытки 1–4, 6–9, 11–14 → 401 "Осталось попыток: N"
         │     ├── Попытка 5 или 10 → кулдаун 5 мин → 429
         │     └── Попытка 15 → status → "blocked" + email-уведомление → 423
         │
         └── Верный PIN → сброс счётчиков → session_token
```

### Разблокировка

```
POST /request-unlock { email }
         │
         ▼
  Поиск заблокированного пользователя по email
         │
         ▼
  Генерация 6-значного кода → Redis (TTL 10 мин)
         │
         ▼
  RabbitMQ → notification_service → email с кодом

POST /unlock { email, code }
         │
         ▼
  Проверка кода в Redis
         │
         ▼
  status → "active", сброс rate-limit, email-уведомление
```

### Выход

```
POST /logout       → удаление текущего токена из Redis
POST /logout-all   → удаление всех токенов пользователя из Redis
```

## Rate-limiting PIN-кода

| Этап              | Неудачные попытки | Реакция                                      |
|-------------------|-------------------|----------------------------------------------|
| Блок 1            | 1–4               | 401 с указанием оставшихся попыток           |
| Кулдаун 1         | 5                 | 429 + кулдаун 5 минут                        |
| Блок 2            | 6–9               | 401 с указанием оставшихся попыток           |
| Кулдаун 2         | 10                | 429 + кулдаун 5 минут                        |
| Блок 3            | 11–14             | 401 с указанием оставшихся попыток           |
| Блокировка        | 15                | 423 + status → `blocked` + email-уведомление |

## Обработка ошибок

| Код  | Когда                                            |
|------|--------------------------------------------------|
| 400  | Ошибка валидации данных / неверный код разблокировки |
| 401  | Неверный PIN-код / PIN не установлен             |
| 404  | Пользователь не найден                           |
| 409  | Аккаунт не заблокирован (при попытке разблокировки) |
| 423  | Аккаунт заблокирован                             |
| 429  | Кулдаун после 5 неудачных попыток                |

## Хранение (Redis)

| Ключ                             | Тип    | TTL    | Описание                                     |
|----------------------------------|--------|--------|----------------------------------------------|
| `session:token:{token}`          | Hash   | 30 мин | Данные сессии (`user_id` + payload)           |
| `session:user:{user_id}`         | Set    | 30 мин | Множество активных токенов пользователя      |
| `rate:pin:{phone}:total`         | String | —      | Счётчик неудачных попыток ввода PIN          |
| `rate:pin:{phone}:cooldown`      | String | 5 мин  | Флаг кулдауна                                |
| `unlock:{user_id}:code`          | String | 10 мин | 6-значный код разблокировки                  |
