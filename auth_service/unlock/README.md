# Unlock

Модуль разблокировки аккаунта после превышения лимита неудачных попыток ввода PIN.

## Файловая архитектура
```
unlock/
├── router.py                # Эндпоинты /request-unlock, /unlock
├── service.py               # Поиск по email, генерация кода, разблокировка
└── README.md
```

## Поток

1. `POST /request-unlock { email }` — поиск заблокированного пользователя по email, генерация 6-значного кода → Redis (TTL 10 мин), отправка через RabbitMQ → notification_service → SMTP
2. `POST /unlock { email, code }` — проверка кода, `status → "active"`, сброс rate-limit счётчиков, email-уведомление о разблокировке

## Исключения

| Класс               | HTTP | Когда                                    |
|---------------------|------|------------------------------------------|
| `UnlockNotFound`    | 404  | Пользователь с таким email не найден     |
| `UnlockNotBlocked`  | 409  | Аккаунт не заблокирован                  |
| `UnlockInvalidCode` | 400  | Неверный или истёкший код разблокировки   |
| `UnlockError`       | 400  | Общая ошибка разблокировки               |

## Email-шаблоны

| Шаблон             | Когда отправляется                   |
|--------------------|--------------------------------------|
| `unlock_code`      | При запросе кода (`request-unlock`)  |
| `account_unlocked` | После успешной разблокировки         |
