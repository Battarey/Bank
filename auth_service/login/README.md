# Login

Модуль входа по PIN-коду для повторных визитов.

## Файловая архитектура
```
login/
├── router.py                # Эндпоинт /login-pin, обработка ошибок
├── service.py               # Поиск по телефону, проверка PIN, генерация токена
└── README.md
```

## Логика

1. Поиск пользователя по `phone` (JOIN `users` + `contacts`, `status = "active"`)
2. Проверка наличия `pin_hash` (если нет — 401)
3. `bcrypt.checkpw(pin, pin_hash)` (если неверный — 401)
4. Генерация `secrets.token_urlsafe(32)` → сохранение в Redis
5. Возврат `{ session_token, user_id }`

## Исключения

| Класс           | HTTP | Когда                                          |
|-----------------|------|------------------------------------------------|
| `AuthNotFound`  | 404  | Пользователь не найден / неактивен              |
| `AuthForbidden` | 401  | PIN не установлен или неверный              |
| `AuthError`     | 400  | Общая ошибка аутентификации                 |
