# Login

Модуль входа по PIN-коду с rate-limiting и блокировкой аккаунта.

## Файловая архитектура
```
login/
├── router.py                # Эндпоинт /login-pin, обработка ошибок
├── service.py               # Rate-limit, поиск по телефону, PIN, блокировка
└── README.md
```

## Логика

1. Поиск пользователя по `phone` (JOIN `users` + `contacts`, `status IN ("active", "blocked")`)
2. Проверка: `status = "blocked"` → 423 Locked
3. Проверка: кулдаун активен? → 429 Too Many Requests
4. Проверка наличия `pin_hash` (если нет — 401)
5. `bcrypt.checkpw(pin, pin_hash)` (если неверный — фиксация неудачи, возможно кулдаун / блокировка)
6. Успешный вход: сброс счётчиков, генерация `secrets.token_urlsafe(32)` → Redis
7. Возврат `{ session_token, user_id }`

## Rate-limit

- Каждые **5** неудачных попыток → кулдаун **5 минут**
- **3** блока по 5 попыток = **15** суммарно → блокировка аккаунта
- При блокировке отправляется email-уведомление (шаблон `account_locked`)
- Успешный вход сбрасывает все счётчики

## Исключения

| Класс               | HTTP | Когда                                          |
|---------------------|------|------------------------------------------------|
| `AuthNotFound`      | 404  | Пользователь не найден / неактивен              |
| `AuthForbidden`     | 401  | PIN не установлен или неверный                  |
| `AuthCooldown`      | 429  | Кулдаун (5 мин), заголовок `Retry-After`       |
| `AuthAccountLocked` | 423  | Аккаунт заблокирован (15 неудач)               |
| `AuthError`         | 400  | Общая ошибка аутентификации                 |
