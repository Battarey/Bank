# Документация проекта Bank

Добро пожаловать в центр документации банковской платформы. Здесь содержится детальное описание архитектурных решений, механизмов безопасности и инженерных практик, реализованных в проекте.

Для академической работы (НИРС/ВКР) документация структурирована так, чтобы показать не только *что* сделано, но и *почему* были выбраны именно эти технологии и паттерны.
