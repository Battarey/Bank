# Стратегия работы с данными (Polyglot Persistence)

Проект использует принцип **Polyglot Persistence** — выбор наиболее подходящего типа хранилища для конкретной задачи. В системе задействовано 6 баз данных, разделенных по зонам ответственности.

## 📊 Матрица хранилищ

| База данных | Тип | Роль в системе | Почему именно она? |
| :--- | :--- | :--- | :--- |
| **Postgres Core** | SQL / Relational | Основные балансы, счета, транзакции. | Гарантирует ACID, ссылочную целостность и надежность финансовых данных. |
| **Postgres History** | SQL / Append-only | Лог действий пользователей (аудит). | Реляционная структура удобна для построения истории действий, а изоляция от Core защищает основные данные. |
| **Redis Sessions** | NoSQL / Key-Value | Сессии пользователей. | Максимальная скорость чтения/записи и встроенный механизм TTL (автоматическое удаление сессии). |
| **Redis Onboarding** | NoSQL / JSON Stack | Черновики регистрации (KYC). | Redis Stack позволяет хранить сложные JSON-структуры анкет с быстрым доступом на время процесса регистрации. |
| **MongoDB** | NoSQL / Document | Журналы уведомлений и безопасности. | Схема логов может меняться, а TTL-индексы позволяют автоматически очищать старые записи. |
| **ClickHouse** | NoSQL / Columnar | Бизнес-аналитика и OLAP. | Колончатая структура позволяет мгновенно выполнять агрегатные запросы по миллионам транзакций. |

## 🔄 Dual-Write и Консистентность

Для обеспечения аналитики в реальном времени используется паттерн **Dual-Write** (через Event Bus):

1.  Бизнес-транзакция фиксируется в **Postgres Core**.
2.  Событие отправляется в RabbitMQ.
3.  **Log Service** потребляет событие и записывает его в:
    -   **Postgres History** (для точного аудита "кто, что, когда").
    -   **ClickHouse** (для мгновенного отображения в дашбордах аналитики).

## 🚀 Стратегия кэширования

Система использует **Redis Sessions** не только для авторизации, но и для кэширования критически важных, но редко меняющихся данных, чтобы разгрузить основную PostgreSQL при высоких нагрузках на Gateway.
